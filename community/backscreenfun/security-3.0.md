## 2. 发现与修改建议

风险等级是本报告的定性判断，未进行 CVSS 评分或真机利用验证。

### BSF-01 · 中风险：外部广播入口缺少调用方约束

**位置**：`AndroidManifest.xml` 的 `StatusReceiver`；`StatusReceiver.onReceive`；`PlaybackService.pushStatus`。

状态广播接收器设为对外可访问，清单未配置保护它的权限。接收代码核对 action 并截断字符串，但未校验发送者身份，随后更新状态；满足条件时还会尝试启动播放服务。

**影响与前提**：同一设备上的其他应用可能伪造状态或干扰显示。实际后台启动是否成功仍受 Android 版本与运行状态限制；没有证据表明这条路径可以直接执行任意命令。

**修复建议**：默认不导出；确需跨应用接入时使用可验证的授权机制，例如签名权限或明确的配对授权。action 名称和包名不能替代认证。加入调用频率、字段长度与允许值校验。

**复测条件**：独立未授权测试应用不能改变状态，已授权集成仍能正常工作；分别检查前台、后台与停止状态。

### BSF-02 · 中风险：本机状态接口无认证读写

**位置**：`StatusServer.open / handle`；`PlaybackService.statusLine / pushStatus`；`ServiceFeed.diagnostic`。

服务仅监听回环地址，这避免了默认直接监听局域网接口，但回环不代表仅本应用可访问。请求处理未见令牌或调用者认证；诊断读取可返回用户配置的服务标识与状态，状态写入也不要求授权。部分改变状态的路径接受 GET。

**影响与前提**：能够访问同机 TCP 回环接口的应用，在服务运行期间可能读取状态信息或伪造显示。绑定回环使外网直接访问通常不成立；不将问题描述为任意互联网用户都可远程控制。

**证据**：本地隔离处理器测试中，无认证请求得到虚构诊断值，并通过 GET 改变模拟状态。未启动真实 Android 服务，不将该测试当作真机利用成功。

**修复建议**：采用经过认证的本机通信方式，或加入会话令牌和显式启用开关；读取与写入都鉴权，状态修改限制为指定方法。尽量减少诊断返回内容。不要将显示的“批准/完成”状态当作可执行操作的可信授权。

**复测条件**：无凭证和错误凭证的读写均拒绝；合法客户端仍可使用；关闭功能后接口停止，敏感字段不返回给未授权调用方。

### BSF-03 · 中风险：请求行与请求头缺少总量限制

**位置**：`StatusServer.acceptLoop / handle`。

代码为连接设置了读取超时，并限制声明的正文大小，但请求行与请求头使用逐行读取，未见行长度、头部总量或请求总期限限制；连接按顺序处理。状态查询参数也没有统一长度上限。

**影响与前提**：本机恶意或异常客户端可能制造内存压力、占用处理线程或延迟合法请求。4 秒读取超时与正文限制只能部分缓解，不能替代输入总量限制。本次没有在手机上实施内存耗尽或服务阻塞测试。

**证据**：隔离处理器接收 32 KiB 的虚构查询值后仍将其交给状态设置函数；该测试证明缺少长度拒绝，不证明手机一定崩溃。

**修复建议**：限制请求行、每个头部、头部总量、字段长度及总处理时间；超限立即拒绝并关闭连接；限定并发与频率。

**复测条件**：边界长度、超长输入、缓慢输入与连续请求得到有界响应，合法调用不会被长期阻塞；观察内存和线程恢复。

## 7. 后续复核与标记

安全通过重点在于排除报告范围内的系统越权、危险执行和未经授权的信息读取、上传或暴露。优先确认状态接口的实际调用边界与数据范围，并检查设备流量、授权拒绝/撤销和停止行为。桥接功能若属于使用范围，应补充桥接端实现与审查。

普通显示和性能问题可以保留为改进建议；若确认系统安全或信息泄漏威胁，则改为 ❗️ 并暂停该版本公开下载。当前为 🛡️，下载保留。更新 APK 后重新绑定文件哈希与签名，不沿用本版结论。

## 8. 修改建议与可能风险

| 优先级 | 修改建议 | 可能风险与目前证据 |
| --- | --- | --- |
| 优先复核 | 为状态读写加入身份验证与显式开关；减少诊断返回字段 | 同机应用若可访问接口，可能读取 UID、状态消息或伪造状态；代码与隔离测试支持该可能性，实际设备跨应用访问未验证 |
| 优先改进 | 限制状态广播的调用方，对字段作长度和允许值检查 | 外部应用可能干扰背屏状态；后台启动效果受系统限制，未见该路径直接执行任意命令 |
| 稳定性改进 | 限制请求行、请求头总量、字段长度和处理时间 | 异常请求可能造成卡顿、内存压力或接口阻塞；已验证大参数被接收，未验证设备资源耗尽 |
| 补充验证 | 检查 GIF 地址解析与连接一致性、媒体授权撤销、后台停止和桥接端权限 | 这些边界尚未充分覆盖，不能给出已安全通过的结论 |

使用时避免在状态消息中放入密码、令牌或私人内容；不需要的状态联动、在线媒体与后台功能应关闭。以上建议用于降低风险，不能代替修复与复核。
