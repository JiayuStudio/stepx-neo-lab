## 如何阅读标记

| 标记 | 含义 | 下载处理 |
| --- | --- | --- |
| 待检查 | 尚无该文件的检查记录 | 不授予安全验证标记，单独注明收录状态 |
| 🛡️ 未完全通过 | 存在待复核风险、改进建议或未完成验证，尚未确认系统安全或信息泄漏威胁 | 保留下载，报告末尾列明修改建议和可能风险 |
| 已通过哆啦A梦安全验证✅ | 对应报告范围的检查完成，系统安全与信息保护检查通过 | 正常下载，保留版本、哈希、日期与验证范围 |
| ❗️ 安全风险，限制下载 | 有证据确认系统安全或信息泄漏威胁，如越权操作、危险执行、未经授权读取或暴露信息 | 暂停该版本安装包公开下载，保留报告和修复状态，复核后再恢复 |

重点检查系统安全和信息保护。普通功能缺陷、显示干扰、性能问题单列为改进建议，不自动触发下载限制。风险是否确认依据证据判断：清晰的代码路径也可构成证据，不必等到真实损害发生；未完成真机测试也不意味着风险不存在。

每份报告末尾列出**修改建议**和**可能风险**。新版本重新检查，不沿用旧文件的结论。「Neo 已认证」只表示功能适配状态；安全标记不是平台官方认证，也不承诺绝无漏洞。
