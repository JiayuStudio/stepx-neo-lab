当前目录只有这一项社区 APK。网页游戏属于另一类内容，不计入 APK 检查覆盖率。尚未检查的新增 APK 标为“待检查”，不得沿用其他版本标记。

## 如何阅读标记

- **待检查**：尚无该文件的完整检查记录。
- **检查中 / 待复核**：证据尚不足以形成结论。
- **未通过**：存在待修复的问题，或必要的验证尚未完成。
- **已通过哆啦A梦安全验证✅**：仅在对应报告范围的检查通过后，显示于该版本；必须能打开报告查看哈希、范围、日期和限制。不是平台官方认证，也不承诺绝无漏洞。

检查覆盖安装包与签名、权限与组件、反编译或原始代码、网络及数据路径、敏感信息和适用的设备运行验证。保存记录并不意味着所有项目已经安全通过。
