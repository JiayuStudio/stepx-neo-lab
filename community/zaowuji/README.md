## 应用简介

造物集是一个 Step Studio 作品分享社区。在这里可以发现别人做的小游戏、工具网页和 App：网页直接打开就能玩，App 下载安装包即可安装。你也可以发布自己的作品，上传截图、介绍和安装包，收获大家的评分和评论；发布新版本后，下载过的用户会在下次打开时看到升级提示。

以上为收录时提供的功能简介；实际验证范围见下文。
