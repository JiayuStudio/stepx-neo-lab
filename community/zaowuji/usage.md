# 造物集使用教程

> **2026-10-24 更新：** 最新收录 31.0.0；下载见[介绍页](README.md)。下方界面与已实测步骤来自 4.0.0，31.0.0 尚未逐项回归。新旧签名一致，但覆盖升级未实测，升级前先备份。

[应用详情](README.md) · [安全检查报告](security-4.0.0.md) · [社区推荐](../../sections/community-apks.md)

适用版本：4.0.0。作者：木偶，来源：社区群。造物集用于发现和分享 Step Studio 网页、小游戏与 App。

## 1. 安装与登录

1. [下载原始 APK](https://github.com/JiayuStudio/stepx-neo-lab/releases/download/community-zaowuji-v4.0.0/zaowuji-4.0.0.apk)，在手机上打开文件，按系统提示安装。只有系统要求时才为当前下载来源临时允许安装，完成后可关闭该权限。
2. 打开「造物集」，选择「密码登录」或「验证码登录」，填写自己的手机号，并按页面提示完成登录。验证码和密码只在应用中输入。
3. 登录后进入作品列表。测试时由使用者完成登录，已确认登录后的列表能正常加载；两种登录方式未分别完整测试。

本应用的安全状态为 **🛡️ 未完全通过**，使用前可查看报告末尾的风险与建议。

## 2. 找到感兴趣的作品

- 首页选择「全部」「网页」或「App」筛选类型；顶部还有排序入口。
- 卡片展示作品名、介绍、截图和评分信息。点击作品主体进入详情，查看完整介绍与截图。
- 已实测列表、网页筛选及详情展示；排序与全部分类组合未逐项验证。

## 3. 打开网页作品

1. 切换「网页」，找到作品。
2. 点击「浏览器打开」，到手机浏览器中体验。
3. 目标网页可能有自己的登录或游客入口，遵循该作品的说明。造物集登录状态不代表已登录所有第三方作品。

已实测浏览器跳转并加载目标网页；这不代表目标作品全部功能或安全性已验证。

## 4. 下载与安装 App 作品

1. 找到 App 卡片，先查看介绍、作者、版本及文件大小。
2. 点击「下载安装包」。浏览器出现文件下载确认后，核对文件再下载。
3. 下载完成后，从浏览器下载列表或系统文件管理器打开 APK，按系统安装提示继续。
4. 安装后按功能需要授权；不要因为是社区收录就授予所有权限。

本次实测到浏览器下载确认，随后取消。其他作品的文件下载完成、安装与运行没有在本轮验证；造物集中的作品不自动继承研究所的安全标记。

## 5. 发布自己的作品

1. 首页点击右上角「＋」，进入「发布作品」。
2. 选择「网页作品」或「App 安装包」。
3. 填写作品名称与介绍，说明用途、操作方式、适用设备及已知限制。
4. 网页作品填写 Step Studio 发布地址；页面提示支持指定 Step Studio 域名。App 按表单选择安装包。
5. 添加作品截图，页面显示最多 6 张。上传前检查截图、说明和文件中是否含个人资料或密钥。
6. 核对内容后点击「发布」。仅分享自己制作或有权分享的内容。

**本轮只打开并检查了发布表单，未选择私人文件、上传或提交。** 以上后续操作依据界面与内置前端流程整理，成功上传及公开显示仍需验证。

可参考的作品介绍格式：

```text
作品名称：
解决什么问题：
适用设备：
使用步骤：
需要的权限及用途：
版本变化：
已知问题：
```

## 6. 评分、评论与更新

- 作品详情包含评分和评论信息；登录后按页面提供的入口操作。本轮只验证信息展示，没有提交评分或评论。
- 发布者更新作品时，可按作品管理页面的新版本流程填写版本和更新说明、上传新安装包。本轮未执行发布新版本。
- 按应用简介，下载过作品的用户下次打开时会看到升级提示。前端会保存下载版本记录，但“下载过”不一定等于“已安装”；更新提醒尚未实机验证。
- 更新前核对作品来源与版本，重要数据先备份。安装完成后在实际应用里确认版本和运行结果。

## 7. 遇到问题

| 情况 | 建议 |
| --- | --- |
| 一直停在登录页 | 核对登录方式与输入，检查网络；不要反复快速请求验证码 |
| 列表为空或加载失败 | 检查网络、登录状态与所选分类，稍后重新打开 |
| 网页要求再次登录 | 这是目标作品自己的账户体系，先确认域名与来源 |
| 下载后无法安装 | 检查下载是否完整、系统安装来源权限和版本兼容性；不要绕过系统明确的安全警告 |
| 更新提示与实际版本不一致 | 以实际安装应用的版本为准，下载记录可能因取消下载或安装失败而失真 |

教程中的“已实测”只覆盖明确列出的基础操作。修改建议和可能风险统一记录在[安全检查报告末尾](security-4.0.0.md#4-修改建议与可能风险)。
