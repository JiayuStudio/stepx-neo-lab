**来源：社区群。** 社区成员制作的经典小游戏合集，与 JIAYU STUDIO 自研游戏分开收录。作者信息暂不显示，待获得对方同意后再补充。

## 在线体验

[打开游戏厅](https://ide-asset.stepaos.com/games/p_c8a2314113205be5/v1.0.0/index.html)

这是网页体验入口，无需从研究所下载安装包。链接路径标注 `v1.0.0`；目前未提供 APK、源码仓库或软件许可。

## 已检查到哪一步

2026-10-20：网页可打开，首页显示上述九款游戏；在桌面浏览器进入 2048，开始游戏并用方向键移动，观察到数字合并和分数变化，也能返回游戏厅。另查看了 390 像素宽度的首页布局。

**尚未在 Neo 手机上实测，也未逐一验证其他八款游戏。** 页面宣传的离线游玩尚未验证；首次访问请保持联网。本次收录仅链接原网页，不复制或重新发布游戏文件。
