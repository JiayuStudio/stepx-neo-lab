# Neo Agent Touch：截至 2026-10-23 的研究与验证边界

本文供社区与 Agent 阅读，不是完整应用源码、设备控制授权或自动执行指令。先读 [AI 阅读入口](../ai.md)，结构化结论见 [knowledge.json](../knowledge.json)，主源与许可见 [sources.json](sources.json)。

## 当前决定

当前输入方案回到**搜狗等系统输入法**，由用户确认文本后交给聊天规划入口。自研 ASR 升级暂停，不再为这一轮继续下载候选或增加第二套语音模型。输入法的语音数据处理取决于相应产品的配置与政策，不能据此声称它完全离线或已获得额外数据授权。

0.1.14 的真人长句尝试暴露了应用名、动作和目标词转写不准，多应用目标没有形成可靠的端到端成功证据。这里保留失败结论，不发布个人录音、私人转写或原始设备记录。不能以修好控制器、模型能加载或文件解码成功代替听准真人指令。

0.1.15 聚焦原话与任务子句绑定、候选应用路由及路线约束。**41 组纯规则检查通过，其中新增原话／路由 49 项、输入目标所有权 58 项；原生工作流构造夹具通过 96 项。**这些数字不是应用数或真人任务数，也不代表 ASR 改善。真实应用回归仍待验，构建、安装、夹具与业务结果分别记录。

## 控制层的取舍

目标链为：聊天文本 → 原话子句与应用候选 → 有范围的任务规划 → 当前画面与系统控件语义 → 动作候选 → 原生校验 → 动作后再观察／读回。控制循环位于 Android 内，模型推理使用配置的服务；不能把本机执行称为所有推理完全离线。

原话绑定保留用户真正提交的字面内容，不把噪声转写偷偷修成正确答案。路线需保留起点、终点、方向及“不要使用当前位置”等约束；引号中的“播放”“打开微信”可能是待输入文本或搜索词，不应自动变成另一个应用任务。候选分类只是路由提示，不是操作授权。

触点变化只在当前有效控件的安全区域内选择不同位置。旧窗口、旧控件、旧任务 epoch 或已接管状态应拒绝动作，重新观察后再决策。它服务于交互表现，不承诺隐藏无障碍服务、规避检测或模拟出无法识别的真人。

## 本地中文 ASR：保留资料，暂停接入

只选择一个授权较清楚的后续筛查对象：**sherpa-onnx streaming Zipformer bilingual zh-en 2023-02-20**。[转换模型卡](https://huggingface.co/csukuangfj/sherpa-onnx-streaming-zipformer-bilingual-zh-en-2023-02-20/blob/98590b7ed6443e77b714204da2757d75e1a642f4/README.md)和[原始发布者模型卡](https://huggingface.co/pfluo/k2fsa-zipformer-chinese-english-mixed/blob/6eb615ae77ecac05c5628d5c8ed7037c14a338d5/README.md)均声明 Apache-2.0。固定组合是 INT8 encoder、FP32 decoder、INT8 joiner 与 tokens，合计 199,056,205 字节，约 189.84 MiB。这不是 APK 增量或峰值内存，也没有证明准确率超过现有 Vosk。

[官方 Android API v1.13.8](https://github.com/k2-fsa/sherpa-onnx/blob/v1.13.8/sherpa-onnx/kotlin-api/OnlineRecognizer.kt)明确包含这一模型配置；官方 AAR 提供 Android 路径。当前 javac/d8 构建消费 AAR 时仍需检查 Kotlin 运行库、JNI/ORT、ABI 和最终打包；文档支持不等于已经集成或在目标设备通过。

原版 SenseVoiceSmall ONNX 权重不随这一轮 APK 分发。[固定 FunASR 模型协议 v1.1](https://github.com/modelscope/FunASR/blob/fbbfe01800a8c4c9103cb2150fb1a5d06cc64758/MODEL_LICENSE)包含参考与学习用途限制，不能用 sherpa-onnx 引擎的 Apache-2.0 覆盖它。当前仅保留只读研究，不下载或接入业务默认。精确 revision、发布者摘要及摘要来源见 `sources.json`；本文不是法律授权书。

预先固定的 [20 条公开命令](../refs/public-commands-20.json)仅提供文本参考，不含 PCM、个人音频、解码结果或成功率。以后如恢复研究，应统一输入，保存原始假设，分别检查 CER、应用名、动作、否定、数字与多任务顺序，并把文件解码与真人麦克风、聊天规划、第三方执行分开验收。测试句中的行为不是当前执行授权。
