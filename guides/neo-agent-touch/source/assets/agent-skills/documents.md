# 自主文档起草与写入
用户只给题目时，由你按本轮原目标自行生成合适正文，未指定的信息用填写占位符，不索要用户提供原文。仅在用户要求租赁合同时，模板包含当事人、标的、期限、租金押金、交付返还、使用维修、违约解除、争议与签署等结构，不填写真实身份、账号或金额，不替用户签署。介绍、报告等其他文档不得改成合同。
先在 WPS 进入新建 -> 文字 -> 空白文档；不要打开已有文件或付费模板。进入新文档后点正文编辑区域，等输入连接就绪，然后输出 {"action":"document_write","text":"你自行生成的完整正文"}，由本机原生正文适配器执行；text 参数最多8000字符。核对用 {"action":"document_check"}。文件名与正文分别输入，不能把正文写进搜索框、文件名或聊天窗口。
document_write 优先使用当前应用的原生输入连接，工具回执会说明是否核对到文字。工具不确定写入结果时先 document_check 或观察，不重复插入同一正文。可按最新界面进入保存/另存为，选择本地可用位置，按 document_tools.expected_file_name 命名后确认保存。该名称来自原用户明确文件名；未指定时由本轮生成独立安全名。出现同名文件，取消覆盖弹窗，再使用本机更新的 expected_file_name 保存，不打开同名旧文件。无需用户指导每一步。
核对文档正文、名称和保存结果，只有文档创建而没有正文不算完成；保存按钮被点击也不等于已保存。
readback_state=mismatch 表示完整读回正文与本轮预期不同，不能宣告成功、不能重复插入或自动覆盖。content_incomplete 表示正文完全一致，但尚不满足原请求的合同结构，也不能宣告成功。partial、unavailable 均不等于全文核验通过。

使用 {"action":"document_focus"} 聚焦当前任务的原生正文画布，避免受无关同步状态刷新影响。保存发起后按document_tools阶段返回最近列表，打开准确的本任务文件名，再进入编辑、document_focus和document_check读回。不要重复新建；写入成功但未保存/重开不算完成。

修改时优先使用 {"action":"document_replace","find":"上次完整正文中的唯一原文片段","replacement":"修改后的片段"}，由手机保留其余正文并执行原生全文选中、替换和完整一致读回。不能重写无关条款。

重开文件后若已在编辑模式但连接未开始，document_focus会优先使用WPS自己的键盘/编辑按钮；不要重复点画布或重复替换已改好的条款。
