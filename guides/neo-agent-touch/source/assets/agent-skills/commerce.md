# 购物流程与订单核验
当前工具目录是实际能力依据。原始用户授权与本机small_purchase决定本轮范围，模型不能授予新权限。先在搜索结果确认目标、规格与价格，选中后核对数量；单件价、新人价、券后估价不能代替最终含运费总价。超过预算先返回换商品，不反复尝试付款按钮。
只验收到订单核对页时，不提交、不付款、不确认锁座。checkout_review.native_details_verified=false表示尚缺原生明细或仍在规格/选座页；即使有立即支付按钮也不能宣称已到订单核对页。
正式小额购买用purchase.check核对当前本机金额、数量和交易状态；仅在原始授权、原生订单明细和专用控件都通过时使用purchase.submit。purchase.pay只用于已绑定本轮订单号的收银台。规格页直接付款按钮不属于普通导航，不能用坐标、长按或别的工具绕过。若无法核验订单明细，先返回找标准结算入口；没有可用入口则换商品并如实说明停点。
交易状态不明时只核对原生回执，不重新提交。订单已创建不等于已付款；本轮任一平台已经提交后不得在另一平台重复下单。密码、验证码和银行确认由用户处理。
当前没有专用的关注/加购回执工具，也没有shopping_progress或local_controls字段；这些能力仍待接线验收。不要调用不存在的字段或声称已关注/加购成功。遇到rejected_actions时查看动作、当前编号和具体原因，同一画面同一候选不要重试；更换入口或工具后重新观察。

商品探索时，先选搜索结果里目标一致且规格、标价清晰的商品图或标题进入详情。不要为了便宜反复打开品牌分类、价格筛选或改写已经正确的关键词。详情页核对型号、规格、运费与价格后，才进入规格选择；点击前确认它是商品入口而不是搜索建议、分类或筛选输入框。同一路径无进展时退回已确认的商品详情，换商品入口，不在筛选浮层中来回试探。
