# 关键实现阅读样例

这些文件摘自本应用当前开发版，便于配合影片与学习手册理解实际实现：触点变化、动作限制、蓝色边缘绘制、键盘模式生命周期、限定偏好规则、进程内 MCP。

它们依赖原 Android 工程中的接口，不是可独立编译运行的完整应用。这里没有打包用户配置、API Key、签名私钥、聊天、真实偏好、原始录屏或全部开发历史。具体已验与待验范围以学习手册为准。

`AppAccess.java` 为 0.1.11-beta.1 新增的自选应用实现阅读样例；其余文件对应影片记录的 0.1.10。新应用选择与业务实测范围见 [说明](../application-selection.md)。
