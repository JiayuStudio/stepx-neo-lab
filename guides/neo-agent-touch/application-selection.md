# 自选应用：从固定名单到通用视觉

版本：0.1.11-beta.1 · 2026-10-23 · JIAYU STUDIO

旧版不仅界面隐藏了名单外应用，执行入口也会拒绝这些应用。本轮同时调整发现、保存、本机名称解析、规划候选和运行时入口校验。

1. 本机通过 PackageManager 查询 MAIN / LAUNCHER 活动，按包名去重，读取名称、图标、版本和分类。没有桌面启动入口的后台组件不列入。
2. 用户搜索、勾选、分类并设定同类常用应用，结果存入原有本机加密存储。取消勾选即从后续可执行范围移除。刷新列表保留未保存的选择，隐藏的筛选结果不会在保存时被意外取消。
3. 对话规划只接收已选的相关候选及常用标记；候选是数据，不是指令。名称和包名在本机解析，模型不能凭空增加可控应用。
4. 启动和观察阶段重新检查应用仍被选中且可启动。通用应用结合当前画面和系统控件语义探索，不复用别的应用坐标，不把 WPS 专用写入工具套给其他办公应用。
5. 已有的模型接收范围、控制权和失效引用检查继续生效。新应用需要相应的画面接收范围；相同范围会记住。

## 本轮验证

- 发布 APK 在隔离 Android 16 模拟器通过 42 项检查：空 Key、首次应用选择、名单外应用发现、原生图标与类别、保存和撤销、分类常用、候选过滤、本机名称／包名解析、创建任务、真实 WebView 保存回原生范围。两款自有启动器夹具为合成 App，零模型请求、零第三方业务动作。
- 最终 APK 覆盖升级另核对选中与撤销状态保留、非调试标志、启动和 About 版本显示；这不是 0.1.10 真机迁移的独立验收。
- Ego Lite 使用隔离列表核对搜索、隐藏选项保留、30 项批量选择、分类变化移除旧常用、刷新新增条目和窄屏布局。它是前端检查，不是实体手机结果。
- 19 组既有纯 Java 规则回归通过。此前淘宝、美团、WPS 真机记录保持 0.1.10 的版本边界。

目前没有连接实体手机；微信、高德地图、QQ 音乐、企业微信、百度网盘的真实复杂功能尚未在本轮逐项验收。应用会根据画面尝试探索，不能将可选、可启动或合成场景通过外推为所有软件都能完成任意目标。

## 技术依据与代码

采用 Android 官方的 [package visibility / queries](https://developer.android.com/training/package-visibility/declaring) 与现有原生执行链，无需 QUERY_ALL_PACKAGES。也查阅了 [GitHub AOSP PackageManager 查询实现](https://github.com/aosp-mirror/platform_frameworks_base/blob/main/services/core/java/com/android/server/pm/IPackageManagerBase.java)理解平台查询行为；该仓库是归档镜像，仅作源码参考，没有复制实现或新增第三方依赖。

[AppAccess 阅读样例](examples/AppAccess.java)对应本次 Beta。影片中其他阅读样例来自 0.1.10，版本分别标注，不把本轮新增功能当作已进入旧片画面。
