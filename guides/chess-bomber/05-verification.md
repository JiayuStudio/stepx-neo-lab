# 5. 独立测试与当前边界

[返回教程](README.md) · [上一章](04-audio-and-video.md)

以下是本案例截至2026-10-20的历史测试范围。本教程整理没有重新执行整套功能验收，也没有做全面安全审计。

## 按什么顺序测试

| 测试 | 操作 | 观察结果 |
| --- | --- | --- |
| 开始一局 | 进练习，倒数时移动/放弹 | 3→2→1；准备期双方不动、无炸弹；之后才允许操作 |
| 格点移动 | 一次按键、抬起，再按 | 每次一格，不因click叠加走两格 |
| 双指 | 保持方向触点，另指放弹，再抬起/重按 | 不互相取消，不重复落子，cancel后可恢复 |
| 画面适配 | 竖屏、横屏、小高度、长昵称 | 按钮完整、标题横排、无错误横屏提示 |
| 格距与爆炸 | 缩小棋盘后放弹 | 火焰与实际格点对齐，不以固定大图遮住数格 |
| 障碍 | 分别在上下中路前放车/炮 | 车停止；炮穿第一格，第二格停止；障碍不燃烧 |
| 新局与重连 | 大厅再进、再来一局、刷新 | 新局获得新计时，同局不延长截止时间 |
| 账户恢复 | 创建测试身份，再用自己的登录码恢复 | 公开UID一致，秘密凭据不出现在公共信息中 |
| 回放 | 结束真实一局后重放并导出 | 进度前进、初始地图正确、下载视频能播放 |
| 声音 | 大厅→对局→演示→大厅，静音/恢复/刷新 | 场景曲库正确、无叠音、持久设置有效 |

浏览器尺寸曾覆盖320×568、360×640、390×844、412×915、640×240、844×390；静音按钮补充后又检查了相关页面与安全区。安全区注入是模拟，不等于所有手机实际刘海和手势条都通过。

## 独立操作已确认

- 网页双触点序列、多种尺寸布局，反序操作与取消后恢复。
- 物理手机竖屏顺序移动、放弹、躲避，以及早期版本的爆炸对齐。
- 手机上静音图标切换、刷新保留、竖屏操控区，以及后续三秒准备画面的实际显示。
- 账户创建与恢复、公开UID保持，公共排行榜字段检查；没有验证所有账户安全边界。
- 真实练习回放可推进，实际导出的视频可以解码。
- 最新默认八障碍地图：82个非障碍格全部连通；新中路障碍前车停止、炮可穿一格；网页画面位置已核对。
- 音频文件加载与解码、两轮六首对局曲洗牌、静音暂停；演示使用《棋院午后》且循环。
- 60秒新版宣传片的真实AI素材、最终时长、完整解码、画面抽查及浏览器实际播放。

以上分属不同轮次，不能合并表述为“最终版本所有功能已经在真机全通过”。

## Studio报告的检查

Studio最终报告构建及交付门禁通过；八障碍修订报告14个测试文件通过，覆盖引擎、连锁、踢弹、命中、超时、障碍、车炮、准备期、AI、回放和旧地图兼容。联机共享准备时间与刷新行为也有其桌面自测报告。

这些是平台报告，不全部属于独立操作者重新执行的结果。把报告保存下来，同时对最重要的最终路径做外部检查。

## 尚未完成或不能外推的项目

- 实体手机真正同时双指触控。网页模拟通过与顺序点击都不能替代它。
- 最终版本完整的双人真机联机、弱网、掉线重连和跨设备时钟偏差矩阵。
- 手机扬声器的独立听感验收，以及各种系统后台切换后的声音行为。
- UID分配空间耗尽、极端并发、长期在线人数、完整安全和反作弊审计。
- 本案例没有执行原生APK构建物安装验收，公开部署与 APK 安装状态需单独核验。

曾尝试用手机shell权限注入同时双触点，系统终止了测试进程；没有绕过系统限制或把失败写成通过。必要时让人手实际双指试玩，是有效的下一步。

## 测试结束

退出本次测试页，关闭临时视频预览服务，恢复本次调整的旋转设置，清理临时注入文件。保留用户原有程序、账户和开发工程，不为“清理”删除历史版本。测试账户与对局数据是否能删除取决于已授权的管理能力，不凭匿名权限做清库操作。
