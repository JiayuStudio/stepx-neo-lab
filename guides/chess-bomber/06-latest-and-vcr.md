# 最新版本与 90 秒宣传片

[返回教程](README.md)

版本：0.15.2。宣传片采用真实网页画面与 AI 对战，目标 90 秒、1920×1080、30fps 输出，配乐使用《棋院午后》。视频输出帧率与录制实际采样率分别记录。

## 镜头顺序

| 时段 | 内容 | 目的 |
| --- | --- | --- |
| 0–6 秒 | 对战高光，落子与闪避 | 先让观众看见游戏的乐趣 |
| 6–17 秒 | 左手移动、右手放弹 | 三秒看懂操作 |
| 17–26 秒 | 六种棋子范围 | 象棋走法变成爆炸战术 |
| 26–36 秒 | 半透明危险格与逃生 | 危险看得见，退路要预判 |
| 36–45 秒 | 踢弹与连锁 | 炸弹还能被踢走 |
| 45–54 秒 | 八障碍、车炮差别 | 绕行与穿一格的战术 |
| 54–63 秒 | 大厅、公开观战 | 可以对战，也可以看别人出招 |
| 63–72 秒 | 战绩、回放、导出 | 复盘精彩操作 |
| 72–80 秒 | 音乐、静音、短局规则 | 随时玩一局 |
| 80–90 秒 | 高光与试玩邀请 | 下一局换你上场 |

只展示已存在的功能。规则说明与实录分开标注，AI 素材不伪装成人类玩家对战。MP4 导出有浏览器兼容限制，完整说明见测试章节。
