# 可复制的 Studio 提示词

[返回教程](README.md)

按当前项目阶段选用，一次提交一个可验收目标。以下是根据实际迭代整理的模板，不是已从空工程逐条复跑的脚本。将角色名称等换成自己的项目内容；先等待当前轮完成并检查结果，再提交下一轮。

## A. 最小可玩版

```text
在当前工程做一个二维象棋炸弹对战原型。9×10交叉点棋盘，红帅和黑将是可移动角色。
先实现一次输入移动一格、放下一枚兵炸弹、3秒引信、爆炸伤害和胜负结束。
角色与炸弹外观明确区分，火焰以实际格距缩放。
先支持玩家对简单AI，完成一局后能重新开始；暂不扩展排行榜和音乐。
请说明状态结构、核心规则函数及实际测试结果，保留历史版本，不发布。
```

## B. 六种棋子与障碍

```text
加入仕、相、马、车、炮、兵六种炸弹：仕斜一格、相田字且塞象眼、马日字且蹩马腿、
车直线至边界、炮直线最多五格、兵向前一格且过河后可左右。
只有炮每个方向能穿一格障碍，第二格停止；车遇第一格立即停止。障碍不燃烧，不能站人或落子。
车炮遇其他炸弹触发连锁并停止继续延伸。
伤害、AI危险判断及范围说明使用一致的规则。补四方向对照测试，不只改文案。
```

## C. 竖屏与双指修复

```text
修复移动时不能同时放弹。每个pointerId独立管理，正确处理up/cancel，防止pointerdown和click重复执行。
一次按键一格，移动和放弹互不锁定。竖屏参考掌机：状态/棋盘在上，选弹在中，左方向右落子在下。
横屏按可用宽高布局，不强迫已横屏设备再次旋转。适配浏览器栏、安全区、小高度和长昵称。
检查320×568、390×844、844×390、640×240；报告模拟触点与真机测试的区别。
```

## D. 账号、大厅与排行

```text
首次进入要求称呼，用于大厅及排行。另有公开唯一数字UID，从五位起，用满自然加一位；服务端保证唯一分配。
给每个账户独立的大小写字母数字登录码，末位做输入校验；登录码为秘密凭据，不能进入公开列表或日志。
支持恢复同一账户且UID保持。大厅显示在线玩家、对战状态及正在进行的房间。
排行显示胜局、负局和胜率，明确平局与胜率分母口径。显示双方RTT毫秒，未知值不要伪装成0。
验证注册、恢复、公共响应字段和状态刷新；说明未覆盖的安全与并发测试。
```

## E. 开局计时与重开

```text
开局前3秒准备，显示3/2/1及提示音；准备期引擎拒绝双方移动和落子，AI也不能行动。
正式开始后才计120秒；超时平局，积分不变。联机共享截止时刻，刷新不延长。
修复新局复用旧deadline：新局使用独立身份，同一局重复请求/重连保持幂等。
验证返回大厅再开、结算后再来一局、刷新三条路径；说明服务端代码何时实际部署。
```

## F. 回放与地图更新

```text
记录每局初始状态、规则版本、随机种子和双方带时间的动作，支持随时重放和可播放的视频导出。
新增默认地图障碍(4,2)(4,7)，保留原6格，总计8格；坐标从左上(0,0)起。
把障碍列表写入新局初始快照。旧快照缺字段时用旧地图，不能改写旧对局。
检查出生点出口、所有空地连通、角色不能进入新障碍、车停止/炮可穿，以及旧回放行为。
```

## G. 上传音乐后接入

```text
附件为已经准备好的实际音频，请接入静态资源，不能只写一个占位清单。
大厅使用courtyard两首，对局使用river-rush/bubble-chase/river-sprint共六首，演示使用courtyard-01循环。
曲库洗牌一轮不重复，跨轮不相邻重复；切场景保持单一音乐元素。
首次交互解锁，音乐与音效独立音量，总静音跨页面及刷新保留；首页与对局有直接静音按钮。
加入不同的胜利、失败、平局音效，结果只触发一次。验证加载、解码、换曲、静音及布局。
```

## H. 宣传录制入口

```text
提供60秒AI对AI演示，两边真实使用游戏引擎与AI；一局提前结束后自动下一局。
支持固定种子、暂停/重开和动作日志导出；不显示账户凭据，不写真实排行榜。
使用当前地图和规则，给出可观察的时间与局数。保持游戏画面可单独录制。
视频将在外部剪辑，不要用虚构动画冒充实战。
```
