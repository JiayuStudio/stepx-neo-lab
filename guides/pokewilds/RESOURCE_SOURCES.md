# 图像、中文字形与音乐来源

- 游戏核心、宝可梦轮廓、原作姿态和游戏内音乐来自 [PokeWilds 0.8.11](https://github.com/SheerSt/pokewilds/releases/tag/v0.8.11)。背屏点阵由这些精灵资源转换并调整灰度、轮廓和动作，不宣称宝可梦形象由本项目原创。
- 中文 8×8 基础字形沿用用户提供的旧汉化包 `pokemon-wilds-v0.8.3-cn-v0.1.zip`，本适配重新组织所需字表和中文显示。收到材料中没有可核验的完整原作者与统一许可说明，不据此另行授予原字形许可，也不宣称原字形为独立原创。开发溯源文件中的本机构建路径未随包公开，此处保留素材来源说明。
- 宝可梦、招式和道具名称参考固定版本 PokeAPI 数据及中文宝可梦图鉴，原创沙盒材料由本适配翻译。对应数据与处理脚本在 `source/localization/`。
- 宣传片前屏来自本项目 0.8.14 的 Neo 游戏录屏；背屏展示按实际点阵资源渲染，配乐使用游戏内 `music/national_park1.ogg`。署名为 `JIAYU STUDIO · StepX Neo 研究所`。
