## P0：环境检查

首次运行时检查可用工具。

```text
请检查当前执行环境中的 Notion 接入方式：
1. 报告 Node.js 版本和可用的命令执行工具。
2. 在当前工作区查找 amoo-notion-1.0.1.js、notion-cli.js 或已加载的 Notion 连接器。
3. 找到 CLI 后查看帮助，并执行 config --json，报告 configured 和 credential_source。
4. 汇总可复用入口、缺少的条件与下一步。
```

<a id="p1"></a>

## P1：导入脚本

先附上本教程的 .js.txt 文件，再发送。

```text
请将附件原样保存到执行工作区，文件名为 amoo-notion-1.0.1.js。
预期大小：18823 字节。
预期 SHA-256：bc1fa570e86bd2b23b72d6f3d2f979f8b6934d0a3fba873d3e9e9ec1003717b3
比较附件与保存文件的哈希；已有同名且同哈希文件时直接复用，不同则另存。
确认 Node.js 版本不低于 22 后，执行 --version 与 --help。
报告保存位置、哈希比对结果、Node 版本、CLI 版本及执行结果。
```

<a id="p2"></a>

## P2：配置连接

检查现有配置，或找到首次配置入口。

```text
请使用现有 Notion CLI 检查配置：
1. 执行 config --json，报告 configured 和 credential_source。
2. 已配置时，运行 self --json 确认连接可用。
3. 尚未配置时，说明当前执行环境的凭据设置或交互终端入口，并给出 init 初始化步骤。
4. 配置完成后再次运行 self，报告连接结果。
```

<a id="p3"></a>

## P3：完整启动提示

填写页面链接和任务，版本与校验词由工具读取。

```text
本次任务：【填写任务】。
请先用现有 Notion CLI 和配置读取【Notion 记忆页链接】的最新正文。若使用的是旧版 notion-cli.js，先通过帮助确认命令用法。

读取后简要报告：
- 使用的工具与读取时间；
- 页面中的记忆版本、校验词；
- 正文是否完整，有无截断、未知块或未读取的子页面；
- 一项与本次任务相关的页面信息及所在小节。

读取不完整时说明缺少的部分，按需补读；失败时报告具体原因。
读取成功后，结合页面中的相关偏好与项目资料继续处理本次任务。
```

<a id="p4"></a>

## P4：日常简短启动

适合保存为输入法快捷短语。

```text
请先使用现有 Notion CLI 和配置，读取【Notion 记忆页链接】的最新正文。
简要报告页面版本、校验词与读取完整性，再结合相关偏好处理任务。
读取失败时说明原因。
本次任务：【填写任务】。
```

<a id="p5"></a>

## P5：恢复已有连接

以前读过，现在找不到入口时使用。

```text
此前同一 Amoo 环境已成功读取：【Notion 页面链接】。
请在当前执行工作区定位既有 Notion CLI，检查环境变量或 ~/.config/notion-cli/config.json 是否被 CLI 使用。
依次运行 config、self、read，定位问题出在工具、配置、页面权限还是正文读取。
成功时报告页面当前版本、校验词与完整性；失败时报告具体错误及下一步。
```

<a id="p6"></a>

## P6：更新读取测试

先修改 Notion 中的版本、校验词和一项偏好，再新开聊天发送。

```text
请使用现有 Notion 读取工具重新获取【Notion 页面链接】。
返回本轮读取到的记忆版本、校验词，以及“长期偏好”中的一条信息。
同时报告工具执行结果与正文完整性；读取失败时说明原因。
```

<a id="p7"></a>

## P7：自动读取检查

新聊天先发送普通任务，回答结束后再发送这段。

```text
请检查刚才回答之前已有的工具调用记录：是否读取了我的 Notion 记忆页？
如果有，列出工具名称、调用时间和当时返回的页面版本；没有记录则说明无法确认。
本次只核对既有记录，无需补读页面。
```

<a id="p8"></a>

## P8：记忆更新草稿

将草稿粘贴到 Notion 后，重新读取验证。

```text
请把本次已确认的结论整理为 Notion 工作记忆更新草稿。
按“新增、修订、删除、待确认”分类，分别归入长期偏好或当前项目。
给出可直接粘贴的修改片段，并标出需要更新的版本号、日期和校验词。
当前 CLI 为只读，我会将草稿保存到 Notion 后再重新读取。
```

以上模板基于已成功的 CLI 读取流程整理；本版文案尚未逐套重新做真机测试。
