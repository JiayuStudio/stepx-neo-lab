# 第一款应用 · 口袋计数器

[原创教程](../../sections/tutorials.md) · [完整新手课程](../../courses/official-step-studio/README.md)

打开官方 Step Studio 的应用构建器，用一个按钮练习“需求 → 生成 → 预览 → 修改”。本课于 2026-11-17 改为官方网页流程，课堂应用待实际生成与设备验收。

## 做出第一个版本

1. 打开 https://studio.stepx.com/，选择应用构建器。
2. 输入下面的需求，生成后打开预览，依次点击三次。
3. 确认数字从 0 变为 1、2、3，点击归零回到 0。
4. 修改一处文字，再在预览中核对新内容。

```text
创建一个手机优先的“口袋计数器”小应用。
页面显示标题、从 0 开始的数字、“加一”和“归零”两个按钮。
点击加一时增加 1，归零时回到 0。数字仅在本次打开期间保留。
使用当前官方组件，按钮方便手指点击，并提供键盘焦点。
先做这一个页面，完成后列出三次加一、归零、重新打开的测试步骤。
```

## 验收与继续修改

连续加一、归零和重新打开分别检查，手机宽度下文字和按钮都完整可见。再逐次尝试减一、修改配色和保存数字，每次完成一项再验证下一项。

需要安装到手机时，按当前官方构建与发布界面生成可安装产物，保留错误信息并在手机实际打开后重复测试。详细步骤进入[测试课](../../courses/official-step-studio/04-test.md)和[发布课](../../courses/official-step-studio/07-release.md)。
