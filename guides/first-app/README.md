# 第一款应用：在 Neo 上制作口袋计数器

[新人入门](../../sections/start-here.md) · [StepX Neo Studio 指南](../neo-studio/README.md) · [研究所首页](../../README.md)

JIAYU STUDIO 原创教程 · 2026-10-20。以下界面名称依据 StepX Neo Studio 1.2.3，其他版本可能略有调整。

目标很简单：做一个有标题和按钮的小应用，每点击一次，数字增加 1；最后把它装进手机，从桌面独立打开。

## 开始前

在 Neo 上安装 [StepX Neo Studio](https://github.com/JiayuStudio/stepx-neo-studio/releases/tag/v1.2.3)。它是 **JIAYU STUDIO 开发的第三方 Android 工具**；官方网页平台入口是 [Step Studio](https://studio.stepx.com/)。本文使用前者的本地项目功能。

基础练习使用内置计数器模板，无需登录云端项目、配置 AI Key 或购买模型额度。下载工具需要联网，下面的编辑、预览和构建在本机完成。

## 1. 新建自己的项目

1. 打开「本地项目」页面，点 **「＋ 新建项目」**。
2. 项目名称填写 **「口袋计数器」**。
3. 创建后进入编辑器，会有三个文件：

| 文件 | 负责什么 |
| --- | --- |
| `index.html` | 页面标题、文字和按钮 |
| `style.css` | 颜色、字号与布局 |
| `app.js` | 按钮点击后数字增加的逻辑 |

内置模板已经有「点按计数 · 0」按钮。先让这个最小应用跑起来，不必从空白代码开始。

## 2. 改成你的应用

在 `index.html` 中做两处小修改：

- 把 `<title>我的 Neo 应用</title>` 改成 `<title>口袋计数器</title>`。
- 把 `<h1>你好，Neo</h1>` 改成 `<h1>口袋计数器</h1>`。

编辑器会把草稿保存在本机。若想换颜色，可在 `style.css` 中修改 `background` 后的颜色值；先保留按钮的 `id="count"`，因为 `app.js` 通过它找到按钮。

## 3. 本地运行，先检查按钮

点编辑器顶部 **「本地运行 ▷」**，应看到你改过的标题和计数按钮。

依次点击三次，确认数字为 **1 → 2 → 3**。再检查文字是否完整、按钮是否容易点击。

修改代码后，关闭预览并重新点「本地运行」。预览中的「重载」运行的是当前快照；重新打开才能载入刚改好的源码。

这个初始模板只在当前运行期间保存数字，重新打开后从 0 开始。这是基础版本的预期行为，稍后可以再加持久保存。

## 4. 构建 APK 并安装

1. 回到编辑器，点底部 **「构建 APK」**。看不到按钮时，横向滑动底部工具栏。
2. 选择 **「构建并安装到 Neo」**，等待本机构建完成。
3. 按 Android 系统安装页的提示确认；首次安装可能需要允许该来源安装应用，再返回继续。
4. 安装成功后回到桌面，打开新应用，重复刚才的三次点击。

也可以先选「构建 APK」，完成后导出安装包。**源码 ZIP 与 APK 用途不同：ZIP 用于继续开发，APK 用于安装。**

## 5. 保存可继续修改的源码

回到项目编辑器，点 **「导出 ZIP」**。保留项目源码，以后可以继续调整功能；安装包本身不是源码备份。

基础练习完成时，你应能确认：

- [ ] 预览显示「口袋计数器」。
- [ ] 点击三次，数字依次变为 1、2、3。
- [ ] APK 能安装，桌面入口可以独立打开。
- [ ] 独立应用中按钮同样可用，重新打开从 0 开始。
- [ ] 已导出源码 ZIP。

## 可选：让 AI 加一个小功能

完成基础练习后，再配置你选择的模型服务或本地模型，在 AI 助手里把「目标项目」选为「口袋计数器」。外部 API 的费用与本地模型要求见对应服务说明，基础练习不依赖它们。

一次只提一个需求，例如：

```text
请修改当前“口袋计数器”项目：增加一个“归零”按钮。
保留原来的计数按钮和三个文件结构，不增加外部依赖。
完成后说明修改了哪些文件，并给我三个手动验证步骤。
```

先在本地预览里确认新功能，再重新构建并安装。之后可以依次尝试「退出后记住数字」「增加减一按钮」「调整配色」，每次只改一件事。

## 遇到问题时

| 现象 | 先检查 |
| --- | --- |
| 修改后预览还是旧文字 | 关闭预览，再从编辑器打开「本地运行」 |
| 按钮不再计数 | `id="count"` 和 `app.js` 引用是否保留；先撤销最近一次改动 |
| 找不到构建入口 | 横向滑动编辑器底部工具栏 |
| APK 构建失败 | 查看具体错误；先用未增加依赖的内置模板构建，避免同时引入复杂项目 |
| 系统阻止安装 | 按系统说明检查安装来源、签名或版本提示，不要绕过系统错误盲目重装 |

本文从本地 Web 模板起步；任意 Java/Kotlin/Gradle 工程、未内置的 npm 包或后台服务需要各自的开发环境。后续能力与限制请读 [StepX Neo Studio 完整指南](../neo-studio/README.md)。
