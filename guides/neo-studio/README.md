# StepX Neo Studio

独立第三方 Android 客户端，为 Neo 提供官方 Studio、本地 Web 项目开发和多模型协作入口。当前版本 **1.1.8**，2026-10-18。

[公开源码与完整文档](https://github.com/JiayuStudio/neo-studio) · [下载正式APK](https://github.com/JiayuStudio/neo-studio/releases/tag/v1.1.8) · [来源与许可](https://github.com/JiayuStudio/neo-studio/blob/main/ATTRIBUTION.md) · [返回研究所](../../README.md)

## 可以做什么

- Neo屏幕和键盘适配，紧凑布局，灰橙配色与轻拟物图标。
- 官方Studio登录与云端构建；本地HTML/CSS/JS项目编辑、预览、导入导出，并通过预编译运行壳离线生成APK。
- 自定义HTTPS AI API、检测与选择模型、多配置；DeepSeek和Studio可围绕同一项目进行前台有界的规划、开发、审查往返。
- Step／Studio和第三方API用量分开记录。支持读取当前Studio项目已落盘SDK日志的真实Token，显示输入/输出/缓存和统计范围；账户余额仍未知，不伪造总数。
- 生成App可经确认调用工作台AI接口、回传调试报告；Amoo任务通过可见分享入口交接，发送与结果回填仍需人工核对。
- 在App中检查GitHub正式Release，查看说明、下载并验证APK，再通过Android确认更新。

## 在 Neo 本地运行

编辑器点“本地运行 ▷”，云端同步的 React/TSX 项目也会在手机编译和执行。编译器、Tailwind 3 和常用依赖已内置，不借助 Mac 或云端构建。默认离线；需要 HTTPS 接口时手动开启“联网”，仍受 CORS 限制。修改源码后关闭预览再运行；“重载”只重跑当前快照。

已实测计数器真实触摸、塔防启动/开始波次/暂停/回到主菜单，以及嵌套资源、TSX、Tailwind、缺依赖/版本错误等11项检查。未内置的npm包会明确报错；Vite/Node/原生桥接不执行。复杂源码独立APK仍由Studio构建，原根目录Web项目离线打包保留。界面以StepX Neo为品牌，不添加模型厂商联名宣传。

## AI 助手开关与云端源码

- 在“本地项目 → 功能与显示设置”切换 AI 助手，右上角菜单也可操作。关闭后底栏和顶部联动入口隐藏，配置、聊天与用量保留，重启仍保持选择；正在执行的任务需先结束。
- 点“同步云端项目 ↓”，选择当前 Studio 登录账号的项目，下载源码至本地；重复同步更新已有副本。
- 编辑器点“上传项目 ↑”：首次确认后创建并关联云端项目，自动准备工作区、上传并逐文件回读校验；以后继续上传到同一项目。上传不会自动删除云端其他文件。
- 已关联项目点“同步到本地 ↓”拉取更新。双方修改不同文件时合并；同一文件双方改成不同内容时拒绝覆盖，并保留本地文件。同步前会保留恢复快照。
- 支持多级文本源码和二进制资源，每项目最多300文件、单文件1MB、合计4MB；密钥、签名配置、依赖和构建目录排除并列明。云端源码可编辑和导出ZIP，复杂工程继续交给 Studio 构建；现有ZIP导入仍面向根目录Web项目。

1.1.7 在 Neo 实测首次上传、嵌套目录与二进制回读、独立修改合并、同文件冲突拒绝、ZIP导出均通过；20项原生云端文件检查及10项传输测试通过。测试项目已清理，原配置、聊天、用量与最近删除记录保留。传输使用当日官方站内接口，需联网、登录并保持前台；不是实时后台同步，传输期间请暂停其他端编辑。

## 指定项目交给 AI 开发

1. 在“本地项目”新建或打开项目，再进入 AI 助手。
2. 选择“目标项目”和工作方式：直接修改、先审查，或只讨论。每轮自动读取最新全部文件和调试报告。
3. 点“修改此项目”，结果通过校验后写回原项目，保留最近5次快照；切换项目不会让结果写错地方。文件已被其他编辑修改、输出截断、取消或格式不合法时不覆盖。
4. 展开“项目操作与写入说明”，可以查看文件、预览、恢复文件，或进入本机/云端构建。协作页“实现任务”使用同一写入通道。

## Neo 套餐额度：仍未接通账号余额

2026-10-18 在 Neo 实机「设置 → STEPX 账号 → 订阅和权益」核对，官方规则为**每月 100 亿 Token，激活后连续发放 12 个月**，覆盖 Neo 的 AI 服务和 Step Studio 创作能力。该页面展示权益说明，没有显示本账号当前周期、已发放额度或剩余额度。

**1.1.8 仍不能读取套餐总额和剩余额度。** 下方项目日志功能只统计局部消耗，不能用于推算套餐余额。尚未定位到可用的官方账号余额接口；StepFun Step Plan、开放平台余额也不能代替 Neo 套餐账本。

## Studio 项目 Token

1. 在 Studio 登录并打开要读取的具体项目，等正在生成的任务完成。
2. 到 Token 页点击「读取 Studio 当前项目」，确认后自动发送只读诊断并等待结果。需要保持前台，诊断本身会消耗 Studio 额度。
3. 查看非缓存输入、输出、缓存读取/写入、去重请求数，以及**日志截止时间和读取时间**。重复读取替换旧快照，最近30个项目可切换，报告可导出JSON。

1.1.6已在Neo实机验证：固定扫描脚本 → Bash真实工具输出 → 校验 → App保存与显示，重复读取不累加。已有草稿或任务会保留，未确认送达不自动重发。失败保留旧报告；应用重启也不会重复发起诊断。界面显示的范围只来自当前项目已落盘日志，可能滞后、轮换或缺失，通常不含本次诊断；不是账号截至现在的完整消耗、套餐总额度或余额。官方历史接口仍未提供主会话Token，因此旧“检查历史接口”仍保留为诊断入口。

Studio项目报告与DeepSeek等第三方API、阶跃直连API完全分开；今日/累计与“导出API CSV”只筛选API账本，项目报告另行导出。依赖当日观察到的站内接口和SDK日志，不是官方公开稳定SDK。其他项目的日志可读性仍需逐项验证。

## 本地项目删除

- **长按项目**：弹出“打开项目 / 删除项目”菜单；右侧“⋯”也能打开。
- **向左滑动**：露出删除按钮，点击后再次确认；轻点项目名称仍进入编辑器。
- **最近删除**：列表底部进入，可恢复完整项目，也可再次确认彻底删除。不会自动过期，保留时仍占本机空间。
- 删除只作用于本地项目。云端项目、已导出文件、已安装App、独立AI对话和Token账本保留；彻底删除会同时清理工作台内该项目的构建APK。
- AI、联动、构建或交接任务进行中，请先结束任务再删除项目。

## 安装和更新

首次在发布页下载 `StepXNeoStudio-1.1.8-release.apk` 并安装。已有版本直接覆盖安装，不要卸载；包名和签名一致时保留原项目、API配置及Token记录。别人安装这个APK不会得到开发者的个人配置或密钥。

1. 打开右上角“⋯”，在菜单底部选“检查更新”；使用说明页也有入口。
2. 点击检查，出现新版本后查看说明并下载。
3. 校验通过后点安装；首次按Android提示允许来源，再返回点击安装，系统会再次确认。
4. 可选择启动时每天检查一次；默认关闭，不会自动下载或静默安装。

更新源为公开GitHub仓库，不需要GitHub令牌。源码有新提交不代表有可安装的新版本；只有正式Release及匹配APK会显示更新。网络需能连接GitHub。

## 实测与限制

设备为STEPX Neo PZ261A，Android 16/API36。本轮23项更新器校验测试通过，覆盖版本比较、异常资产、非HTTPS/非法主机以及损坏、异签名、异包名、调试和降级APK拒绝；联动DOM8场景与Token分账回归通过。真实更新链路已通过：手机无令牌读取公开GitHub、下载正式APK、校验后进入Android安装器并成功升级到1.1.3；已安装包哈希与发布包一致。首次测试使用带新更新器的112引导包，原版1.1.2本身仍需手动首次升级。1.1.4在Neo上完成16项状态迁移自测和20项实机流程检查：长按/左滑、删除取消、重启后恢复、彻底删除及缓存清理通过；原有项目、配置、独立对话和Token记录完整JSON哈希不变。1.1.5增加21项原生文件校验与11项实机写入流程，实际DeepSeek修改原项目、Neo本机生成签名APK、安装后加一/归零触摸通过；测试App和模拟数据已清理，真实662 Token调用保留。原配置/对话/最近删除及既有用量不变。完整版本验收以[验收记录](https://github.com/JiayuStudio/neo-studio/blob/main/验收记录.md)为准。

本机离线构建适用于支持的Web项目，不是任意Java/Kotlin/Gradle/npm工程编译器。自动联动需保持前台，最多1–3轮，与本版手动源码上传/下载是独立入口。官方云端模型不能由本地DeepSeek配置替换。没有后台自动控制Amoo，也没有读取其他App的Token账单。新设备首次配置全部功能未重新独立验收。
