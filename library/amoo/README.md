## 先记住三个区别

- **打开应用**与**在应用里完成操作**是两回事。原资料没有证明通用界面点按、滑动和输入已可用。
- **文档中有能力名**与**实际调用成功**是两回事。每条提示词保留证据标签；实测记录中的空白方法栏不作补猜。
- **查询成功**与**下单、发送、支付成功**是两回事。原报告中的未执行项目仍标为未执行。
