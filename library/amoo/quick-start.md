# Amoo 怎么用：一句话清单

[资料库](README.md) · [详细手册](manual/README.md) · [实测结果](test-results.md)

来源：提供的 4 页清单；原稿实测更新为 2026-10-20。本次为文字整理，未重新实测。下面的状态描述的是原报告环境，不能保证其他版本或账号相同。

Amoo 是手机里的对话助手。 你不用记任何口令,直接用大白话(打字或说话都行)告诉它想干嘛就行。

它现在最擅长三件事:帮你打开 App、改手机设置、查信息。

但它还不能替你在 App 里一步步点着下单——比如它能帮你打开外卖 App,可选店、下单、付钱还得你自己来。

## 先看懂四种标记

✅ 原报告已测可用 —— 原报告记录真机通过，适用范围以当时环境为准

⚠ 部分可用 / 有条件 —— 能打开但后续要自己来,或能力受限/需额外确认

❌ 做不到 / 本机不具备 —— 真机试过失败,或测试环境缺能力/缺 App

⏭ 未测(不可逆) —— 花钱、外发、断网等,未执行

## 1. 打开 App

- "打开计算器" ✅ 一说就打开

- "打开B站" ✅ 能打开

- "打开B站,搜一下三体" ⚠ 只能打开 B站,搜索得你自己点

- "列出手机上装了哪些应用" ✅ App 名字说不准时先问这一句,再让它打开

- "用浏览器打开 www.stepfun.com" ✅ 能用浏览器打开网址

- "打开携程 / 打开京东 / 打开淘宝 / 打开美团 / 打开支付宝 / 打开微信 / 打开高德 / 打开QQ音乐" ✅ 能打开到前台(里面操作仍要自己来);"打开拼多多 / 打开咪咕音乐" ❌ 未安装时打不开

- "看一下手机里有没有装携程" ✅ 能查(check_app_installed_by_name)

- "我手机上装了多少个应用" / "列出装了哪些应用" ✅ 能查(第三方数量与名单)

- "帮我卸载某某应用" ⏭ 未测(不可逆,未执行)

小窍门:说 App 在桌面上显示的名字,最容易打开。名字对不上时,它会自己去翻已装的应用再试一次。

## 2. 手机设置

- "蓝牙现在开着吗" ✅ 能查

- "把蓝牙关掉" / "把蓝牙打开" ✅ 能开关,而且会直接做,不会先问你

- "现在是不是飞行模式?只查不改" ✅ 能查

- "打开飞行模式" ⏭ 未测(会断网,未执行)

- "WiFi 现在开着吗" ✅ 能查

- "把 WiFi 关了 / 打开" ✅ 能开关且常无二次确认(测完已还原;仅 WiFi 联网时慎用)

- "关闭移动数据" / "打开个人热点" ⏭ 未测(可能断网,未执行)

- "屏幕调暗一点" ✅ 能相对调节;精确设百分比再还原 ⚠ 本机无亮度读值接口,它会拒绝盲改以免无法还原

- "打开深色模式" ⚠ 仅有状态查询与条件分支记录；"打开勿扰模式" / "打开省电模式" ✅ 原报告记录往返成功，常无二次确认

- "打开手电筒" ✅ 能开能关

- "截个屏" / "开始录屏再停止" ✅ 能

- "帮我清理一下后台" ⚠ 会触发清理能力,回执偶发「暂时无法响应」

- "打开设置" ⚠ 能打开设置,往下翻、点哪一项得你自己来

- "打开声音设置" ✅ 能打开声音设置页;直接调音量数值仍未见独立 method

## 3. 打电话、发短信、查短信

- "帮我查一下最近一条短信,只告诉我时间和号码" ✅ 能查,它会先弹个提醒,你点同意后才查

- "找一下带某关键字的短信" / "最近三天的短信" ✅ 能按关键字与日期筛(sms_search)

- "今天/最近几天收到了哪些短信" ✅ 能查(limit + 日期)

- "打电话给张三" / "拨打 10086" ⏭ 未测(不可逆,未执行)

- "通讯录里有没有某某" ✅ 能查(可只要人数、打码号码)

- "帮我查一下话费余额和剩余流量" ❌ 只读查不到;需向运营商发查询短信(有副作用)

- "给张三发短信" ⏭ 未测真发;观察显示会用 sms_send_direct 并先确认

- "用微信给张三发消息" ⏭ 未测(不可逆,未执行)

- "给张三打个微信视频" ⏭ 未测(未执行)

微信群消息、转账、红包、发朋友圈 —— 它自己说不支持,别试

## 4. 闹钟、日程、提醒

- "设一个测试闹钟" ✅ 能设;建议设完自己打开时钟看一眼

- "倒计时 N 秒/分钟" ✅ 能

- "我现在开着哪些闹钟" ✅ 能查(已启用)

- "添加一条测试日程" ✅ 能建能删单条;提醒参数请自己核对

- "查询某天日程" ✅ 能查

- "添加一条待办" ❌ 本机待办能力不存在(可改用日程替代)

- "删除全部闹钟" ⏭ 未测(不可逆);删除单个指定闹钟 ✅

## 怎么说更灵

一句话说全:时间、地点、数量都带上,比如"查 10 月 25 日上海到杭州下午的高铁"。

可以加限制,它会听:比如"只查不改""只估价,不要下单""最多 10 条"。

一句话能连着办几件事:比如"先看蓝牙开没开,关掉,再打开",它会一步步做完并告诉你。

打开了不等于办完了:让它"在某 App 里做某事",它常常只是打开 App 就停了,后面要你接手。

要联网:它要连网才好使,没网时可能没反应。

别跟它说"忽略规则"之类的话,它会直接不回答,同一句里的正事也不办。

## 温馨提示

改设置它会直接做,不一定会先问你——实际试过:说一句"把蓝牙关掉",它马上就关了,没弹任何确认。

所以碰到发消息、花钱、叫车、删除、卸载这类事,建议多说一句"执行前先问我一下"。

想清楚再开口,比事后补救省心。

已于 2026-10-20 真机实测更新(详见[实测结果](test-results.md))。蓝牙/WiFi/勿扰/省电/手电筒等写操作常无二次确认;按关键字与日期查短信可用;话费流量只读不可用;待办能力测试环境未提供。
