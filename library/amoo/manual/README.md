## 0. 先读这一页:Amoo 怎么工作、能做什么、做不到什么

### 0.1 一句话从说出口到执行

你说/输入一句话

- 端侧小模型(stepos-sla)先做一次推理

- 对话发往云端 Claw(deployment=CLOUD),由 OpenClawCloudBridge 以 relayInvoke ability.call 下发能力调用

- 中继回本机的本地节点(local node)

- Ability executor / McpCallToolHandler 用 MCP(Model Context Protocol)调用原子能力

- 各能力服务方执行:com.stepos.common.ability.proxy(打开应用等通用能力)、

com.android.settings(设置)、com.android.mms(短信)......

以上调用链在 2026-10-19 的实测中多次复现(●)。几乎每轮对话前,Amoo 会先向云端做一次安全审计状态检查(●)。所以即使是"端侧"能力,整个流程也依赖联网(历史测试报告记载完全断网时音量、计算、天气请求未发送成功,△)。"原子能力"就是一个个带英文方法名(method)的小功能,例如 open_app_by_name(按名称打开应用)、settings_bluetooth_switch(蓝牙开关)、sms_search(短信检索)。你说的话被理解后,最终落到这些 method 上。

### 0.2 诚实边界(全文贯穿)

**调用已注册的原子能力:打开 App、开关部分系统设置、查/读短信、查天气、查航班酒店火车票、打车估价等**

- **做不到(当前)**：在第三方 App 界面内连续点按、滑动、输入(GUI自动化 / GUI Agent)

**用 open_app_by_name 把任意已安装 App 拉到前台**

- **做不到(当前)**：打开 App 之后,在 App 里替你搜索、选店、加购、选房、下单、支付

**通过已对接的云端服务(携程查询、滴滴/曹操估价、什么值得买、咪咕等)直接拿结果**

- **做不到(当前)**：微信群消息、加好友、转账、朋友圈、红包(Amoo 自述不支持,●)

关键事实:gui_agent(App 内 GUI 自动化能力)当前无法经提示词触发。

固件里确有 GUI Agent 代码、模型单元与 gui_agent 工具映射(tool_name_map.json 中 id=0,标签"UI 自动化操作")(◆);StepClaw 内置文档也写了调用约定 gui_agent(app_name, task)(○)。但实测中:显式要求"用 gui_agent 打开设置并滑到关于手机",Amoo 回复"任务失败,原因是能力缺失,不是权限不足",能力检索里找不到 gui_agent,也没有 tap / swipe / input_text / ui_tree 类方法;日志中isGuiAgent=false 全程不变(●)。另一次实测"打开B站,搜索三体":Amoo 只调用了 open_app_by_name 打开 B站,然后原话说明"B站已经打开了,但搜索这一步我执行不了......这类界面内的连续点按操作不支持"(●)。Amoo 官方能力清单(v4)也写明:"无法在应用界面内像真人一样连续点按操作;相关需求由对应服务在后台完成。"(○)

因此:点外卖、订酒店、网购这类"要在 App 里点完才算完成"的任务,Amoo 现在只能做到两件事:1用open_app_by_name 打开对应 App;2如果这个场景有对接好的原子能力(例如携程酒店查询 query_hotel、滴滴估价didi_taxi_estimate),用原子能力完成那一部分。App 内的下单、选房、支付需要你自己动手。

## 1. 证据等级图例(每条提示词都有)

**●实测可用**

- **含义**：本轮(2026-10-19)或前一轮(2026-10-18)在真机上让 Amoo 实际执行过,并有日志/独立状态核对
- **你该怎么理解**：这句话大概率能用;但结果仍以当时真机返回为准

**◆静态存在**

- **含义**：method 名出现在能力明细表 / 能力检索回执 / 固件工具映射里,但未逐条实测
- **你该怎么理解**：有这个能力名 ≠ 这句话一定能用。未实测,以真机返回为准

**○仅文档声明**

- **含义**：只在能力清单、应用对照表等文档里有文字描述,没有可核对的 method名
- **你该怎么理解**：说了可能有效,也可能无效。未实测,以真机返回为准

**△历史口径**

- **含义**：来自更早的测试报告或历史查询记录
- **你该怎么理解**：仅作参考,可能已随版本变化

补充约定:

"◆(明细表)"= 来自《已对接应用能力明细表》(2026-10-18 能力检索回执,104 项,抽样未穷举)。"◆(检索命中)"= 2026-10-19 探测中 Amoo 能力检索实际命中该 method 名,但未调用。

"◆(工具映射)"= 只出现在 Amoo 安装包 tool_name_map.json(UI/路由标签映射),不能证明运行时已注册,比明细表更弱。

"●(能力已实测;该目标 App 未单测)"= method 本身跑通过,但对表中这个具体 App/对象没单独测。表中的人名(张三)、地点、时间均为示例,请替换成你自己的。

## 2. 一页速查:各场景能做到哪一步

**打开 App / 应用管理**

- **能做到**：打开任意已装 App(●)、列出已装应用(●)、浏览器打开链接(●)
- **做不到 / 受限**：App 内任何操作
- **总体**：可用

**点外卖**

- **能做到**：打开外卖 App(●);经支付宝点餐/闪购(○)
- **做不到 / 受限**：美团外卖 App 未接入;App 内选店下单支付
- **总体**：受限

**订酒店 / 机票 /火车票**

- **能做到**：酒店/航班/火车票查询(●);打开携程(●)
- **做不到 / 受限**：预订未测;App 内选房支付仍做不到
- **总体**：查询可用

**打车 / 导航 / 出行**

- **能做到**：路线耗时、附近搜索(●);滴滴估价 ⚠
- **做不到 / 受限**：叫车/真导航未测;估价本轮不完整
- **总体**：部分可用

**购物 / 比价**

- **能做到**：什么值得买比价、好价、评测、参数(◆)
- **做不到 / 受限**：京东未接入(○);淘宝/拼多多 App 内下单
- **总体**：受限

**通讯**

- **能做到**：读/检索短信(●,有风险确认);打电话、查联系人、发短信(◆);微信个人消息/通话(◆/○)
- **做不到 / 受限**：微信群消息、转账、红包等
- **总体**：部分可用

**系统设置**

- **能做到**：蓝牙/WiFi/勿扰/省电/手电筒/截录屏/声音页(●);亮度相对调节(●)
- **做不到 / 受限**：飞行/蜂窝/热点未测;亮度缺读值
- **总体**：大部分可用

**闹钟 / 日程 / 提醒**

- **能做到**：闹钟增删查、倒计时、日程增删查(●)
- **做不到 / 受限**：待办能力测试环境未提供(❌);删全部闹钟未测
- **总体**：大部分可用

**天气 / 信息查询**

- **能做到**：本地/城市天气、定位、世界时间、网页搜索、行情(●)
- **做不到 / 受限**：知乎未测
- **总体**：可用

**音乐 / 媒体**

- **能做到**：咪咕推荐播放(◆)、相册检索(◆)
- **做不到 / 受限**：未接入的音乐 App 只能打开
- **总体**：受限(未实测)

**生活服务**

- **能做到**：打开支付宝缴费/充值/乘车码等入口(◆工具映射);支付宝内缴费、挂号、快递(○)
- **做不到 / 受限**：支付与密码需你本人确认
- **总体**：受限
