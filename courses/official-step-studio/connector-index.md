# 连接器课程导航

[课程首页](README.md) · [官方应用连接器目录](https://studio.stepx.com/connectors)

2026-11-23：官方应用构建器显示 **43 项**，本版 **40 门练习＋3 项暂缓**。先学习单个只读能力，再学设备操作，最后进入需要网页授权的服务。网页授权仍可能需要服务账号及可用额度，不等于免费或无需登录。

## 推荐顺序

1. **入门**：计算器 → 天气/云端天气 → TTS；先学输入、调用和结果。
2. **手机工具**：时钟、日历、设置、文件与图库；先查后改，关注权限和恢复。
3. **设备特色**：背面点阵屏、触觉、主屏、摄像头与音频；必须在兼容手机验收。
4. **办公协作**：XMind → 腾讯问卷 → 金数据 → 轻流，逐步学习 OAuth、对象标识、字段和统计。
5. **专业数据**：八爪鱼、FastMoss、天眼查、元典、晨星；先做小范围只读查询，核对账号权限、来源与额度。

高德和百度网盘需要开发者自行申请配置；支付宝涉及收款，三项暂缓。元典、晨星只讲官方说明中的网页授权路径，若当前弹窗只提供手填令牌，就停在配置前。
