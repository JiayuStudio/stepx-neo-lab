# 蓝牙链接：蓝牙状态卡

[课程导航](../README.md) · [连接器总表](../connector-index.md) · [官方详情](https://studio.stepx.com/connectors/ic_atomic_990015)

2026-11-17 核对；官方版本 **1.0.2**，当前能力表 **3 项**。本课提供开发步骤与验收方法，尚未代替你完成授权、调用或真机验收。

## 这一课做什么

查询蓝牙状态，并提供打开蓝牙设置的入口。

## 添加与准备

1. 打开官方 Step Studio，新建或进入一个测试用应用项目。
2. 打开「连接器」，搜索「蓝牙链接」，查看详情后选择「添加到项目」。选择刚建的测试项目。
3. 在兼容的 Neo 设备上按提示授予本课所需权限；不需要自行申请 API Key。
4. 让 Studio 读取当前连接器说明与参数，先完成一个最小动作。资料不足时先显示待配置，不用假数据冒充成功。

## 按顺序实现

先实现上述目标中的一项动作。为输入、执行中、结果和失败分别留出位置；依据连接器真实参数生成调用，在支持的 Neo 手机上观察结果。

完成第一次调用后，再加入第二项操作；查询应显示真实返回，修改应在手机或对应应用里复核实际效果。

| 起步能力 | 用途 | 当前必填参数 |
| --- | --- | --- |
| `settings_get_bluetooth_state` | 获取蓝牙状态 | 无必填字段（仍核对可选项） |
| `connectivitysettings_open_settings_bluetooth_settings_activity` | 打开蓝牙设置页 | 无必填字段（仍核对可选项） |

参数类型、可选值和返回字段，以项目内当前 schema 为准；复制名字不等于接口已经接通。

## 验收与下一步

- 正常输入：记录一次调用的输入、真实返回与页面结果；数字、单位和对象相互一致。
- 未授权或拒绝权限：显示需要连接或授权，不能显示成功。
