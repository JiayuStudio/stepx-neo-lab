# 08 · 从本地清单到共享目录与后台

[课程首页](README.md) · [官方应用知识库](../../official/step-studio-knowledge/README.md)

本课做免费课程目录：普通用户只看已发布课程，编辑者维护标题和简介。先不接支付。

1. 先确定字段：课程 id、标题、简介、发布状态；不把组件中的示例数字当真实记录。
2. 使用卡片显示用户端，表单编辑后台。保存状态需对应服务端成功或失败。
3. 明确谁能读、创建、修改和删除；隐藏按钮不能代替服务端权限。
4. 先用测试记录验证保存、刷新、并发修改和权限拒绝，再放正式资料。

```text
把课堂清单扩展为免费课程目录与编辑后台。
先列数据字段、普通用户和编辑者的权限表，再说明服务端如何检查。
禁止只靠前端按钮控制权限；错误时保留输入，不假装保存成功。
不接入支付、不要求自行申请第三方凭证。若平台当前不支持必要权限，请停在明确的待完成状态。
```

完成条件：普通用户不能修改数据；编辑者保存后其他页面能读到正确内容；取消和失败不产生半条记录。本课依据官方知识库改编，尚未验证服务端或账户权限。
