# 06 · 把两项能力组合成自己的工具

[连接器练习](connector-index.md) · [课程首页](README.md) · [下一课](07-release.md)

先让两项能力单独可用，再串起来。推荐做「城市天气播报卡」：用户输入城市，查到天气后，再由用户决定是否朗读。它不需要自行申请高德凭证。

## 先画出数据怎么走

城市输入 → 云端天气查询 → 天气卡 → 点击朗读 → TTS。查询失败时不能朗读一份看起来成功的默认天气。

```text
在官方 Step Studio 创建「城市天气播报卡」。只使用「云端天气服务」与「TTS」连接器，先读取各自真实 schema。
用户手动输入城市后查询，显示返回中的地点、时间、天气与可用温度字段；未返回字段不编造。
查询成功后显示「朗读这份天气」按钮，由用户点击后播报，并提供停止按钮。
查询失败、空结果或城市变化时禁用旧结果朗读，清楚区分加载、成功与错误。
不要请求当前位置，不使用高德，不引入自行申请 API Key 的服务。
先完成查询并检查，再接朗读；最后给出网页与手机分别验收的步骤。
```

## 第二种方向：背屏小面板

先完成[背面点阵屏](connectors/ic_atomic_990001.md)的只读查询。再增加一个简单图案、清空与恢复原设置。每加一个动作就观察一次物理背屏，不同时扩展动画、闹钟和后台服务。

## 完成条件

一条完整任务能走完；任一步失败都有清楚的反馈；用户能停止或返回。至少保留一份正常结果与一份失败记录，再进入发布整理。
