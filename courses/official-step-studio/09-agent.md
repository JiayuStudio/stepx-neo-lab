# 09 · 智能体路线：会议纪要助手

[课程首页](README.md) · [官方知识库](../../official/step-studio-knowledge/README.md)

不需要先完成组件课。本课目标是把输入文字整理为摘要、决定和待办；不连接私人邮箱或自动发送消息。

1. 在构建器选择中进入智能体构建器，为课堂助手说明用途。
2. 设置输入边界和输出结构，在预览中用虚构会议记录测试。
3. 分别测试正常记录、没有负责人、没有截止日期和内容互相矛盾的情况。
4. 手机上使用前按页面要求完成测试；发布按当前校验与审核结果确认。

```text
你是会议纪要整理助手。只根据提供的文字输出：摘要、已确定事项、待办、待确认问题。
每条待办包含任务、负责人、截止日期；原文没写就标未指定，不编造。
遇到互相矛盾的信息同时列出，不代替用户做决定。不要自动发消息或写入日历。
```

完成条件：事实可逐条追溯到输入；缺失字段没有被补造；用户可在提交前修改输出。此为基于官方知识库的新版练习，尚未实际创建或手机验证。
