# 00 · 把想法变成一个小任务

[课程首页](README.md) · [下一课](01-create.md)

本课使用官方 [Step Studio](https://studio.stepx.com/)，与研究所自研 StepX Neo Studio 是不同工具。

## 先写三行

```text
给谁用：想在手机上整理个人作品的人。
解决什么：能按网页、App 和工具找到作品。
第一次只做：列表、分类、详情，不登录、不上传、不支付。
```

先选择应用构建器；只处理文字可走[智能体](09-agent.md)，重复使用固定规则可走[技能](10-skill.md)。开发、测试、正式版本分别用于编辑、体验与分发，不能用一张预览截图代替全部验收。

## 分清四件事

| 内容 | 作用 | 例子 |
| --- | --- | --- |
| 组件 | 展示信息、提供交互入口 | 卡片、导航、按钮 |
| 数据 | 决定显示的内容 | 作品名称、分类、收藏状态 |
| 业务逻辑 | 决定点击之后做什么 | 点击收藏后保存并刷新 |
| 连接器 | 调用平台或设备能力 | 查询天气、朗读文字 |

先使用虚构、明确标注的示例数据。照片选择、上传、云存储和登录应在确实需要时才加入，不把真实个人资料当教学样本。

## 完成条件

别人读完三行需求卡，能说出对象、主要按钮和成功结果。说不清时先缩小需求，再进入下一课。
