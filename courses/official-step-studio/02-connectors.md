# 接入第一个连接器

[课程首页](README.md) · [43 项连接器课程](connector-index.md)

先做「输入一个数学表达式，点击后显示真实计算结果」，不要一开始组合多个服务。

1. 在官方应用构建器新建测试项目，先做输入框、执行按钮和结果区。
2. 进入连接器目录，搜索「计算器」，阅读详情，点击「添加到项目」。
3. 让 Studio 读取当前参数结构，再把输入框接入表达式参数；不要凭旧教程写死字段名。
4. 显示执行中、结果、表达式错误和设备不支持四种状态。
5. 网页只能验证界面；手机专属能力需要在兼容 Neo 上运行后，才能记为调用成功。

```text
做一个表达式计算卡，使用官方计算器连接器。
读取当前 schema 后再生成调用。按钮点击时执行，展示真实结果和错误。
不能调用时显示待连接或不支持，不用 JavaScript 假算一次冒充连接器成功。
用一个正常表达式和一个不合法表达式列出验收步骤。
```

完成后进入[单课练习](connectors/ic_atomic_474.md)。再学习天气、TTS；掌握基本状态后进入[网页授权服务](connector-index.md)。

新增服务的通用顺序是：添加到测试项目 → 使用者在服务网页授权 → 确认连接成功 → 列出可访问对象 → 用真实标识查询 → 在原服务核对。需要自行申请 API Key 的服务暂不做。官方目录新增不等于你的账号已开通，也不代表研究所已实测。
