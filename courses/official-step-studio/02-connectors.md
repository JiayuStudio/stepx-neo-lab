# 05 · 给界面接入真实能力

[课程首页](README.md) · [连接器练习总表](connector-index.md)

组件负责呈现，连接器负责访问设备或服务。先读官方说明，再把按钮接到明确的一次调用。

1. 先选择应用、智能体或技能构建器，记录当前模式，再在[官方连接器目录](https://studio.stepx.com/connectors)搜索需要的能力。
2. 阅读概览和能力说明，核对只读还是会改变设备、是否要求自行申请凭据。
3. 点「添加到项目」，选择课堂项目；发送前检查项目与连接器卡片。
4. 让 Studio 读取实际接口名称、输入 schema、必填字段和返回格式，再实现一个按钮。
5. 先验证成功，再处理拒绝、取消、空结果与失败。硬件行为必须到手机观察。

```text
给当前课堂项目加入指定连接器的一项只读能力。
先读取实际方法及 input_schema，列出输入、返回、权限和支持环境。
如果文档描述与 schema 冲突，先指出矛盾，不猜参数。
界面包含输入、执行按钮、执行状态、结果和重试。没有设备能力时显示不支持，不返回模拟成功。
```

高德、百度网盘及支付宝暂缓。手机权限弹窗不等于要自行申请 API Key，但仍按真实功能需要授权。

背屏接口特别说明：当前目录有 17 项，不再列出取消倒计时。`set_back_screen_frame` 概览与能力表对 text 参数说法冲突，按所选接口实际 schema 核验；本课程以 frame 数组练习，不宣称文字直传已实测。

目录比较口径：2026-10-24 未登录同轮界面观察中，应用模式显示支付宝、高德地图、百度网盘；切换智能体模式后，同一目录可见高德地图 MCP、企业微信 CLI、飞书 CLI、携程问道旅行等。不同构建器模式的目录不能直接比较为上线、迁移或下架；技能模式需另行核查。10-23 的高德 MCP 基线来自智能体模式，不能据应用模式的不同显示推断它被替换。此处仅记录界面可见，不是发布日期或调用实测，旧 `ic_amap_jsapi` 的凭据暂缓条件继续保留。来源与边界见[本轮核查](../../maintenance/2026-10-24-review.md)。
