# 07 · 发布、审核与交付

[课程首页](README.md) · [测试清单](04-test.md)

先完成当前版本测试，再到工作台使用实际「发布」入口。页面按钮名称和限制可能变化，以当时提示为准。

1. 确认版本与变化，整理已知问题和未测内容。
2. 检查资料、截图和包内配置，只保留可以公开的内容。
3. 按页面完成构建与发布，记录真实状态。
4. 查看安全审核和分发状态。出现“发布成功”不代表之后不会被审核停止分发。
5. 用实际公开入口重新打开页面，或下载并安装交付版本；核对版本和基本功能。

| 作品类型 | 需要分别确认 |
| --- | --- |
| 应用 | 正式版本、分发链接、审核状态；AmooStore 上架另看材料与结果 |
| 智能体 | 校验、协议、发布审核和市场可用状态 |
| 技能 | 校验与机器审核；市场上架按实际人工审核流程确认 |

后三类流程依据官方群知识库整理；当前账号页面结果优先。本版课堂练习未执行正式发布。

交付说明至少包含：用途、版本、安装/打开步骤、权限用途、实测范围、已知问题和反馈方式。发布被拒时先读具体原因并修改，不循环重发相同包。
