# 03 · 用具体反馈修改应用

[上一课](02-connectors.md) · [课程首页](README.md) · [下一课](04-test.md)

生成第一版后，一次改一个问题。最有用的反馈包含：操作、实际结果、预期结果、保留什么。

## 修错误

```text
在课堂计算器中，清空输入后点击计算，结果区域一直显示「计算中」。
预期：立即提示「请输入算式」，不调用连接器，并能继续输入。
请定位输入校验与状态复位，只修这个问题，保留现有布局和正确的计算流程。
完成后验证空输入、正常输入 12*(3+4)、错误输入 12*( 三种情况，并分别说明是否实际执行。
```

## 改界面

```text
只调整当前页面的可读性：手机宽度下按钮易点，标签不截断，长错误信息自动换行。
保留现有连接器调用、状态逻辑和输入内容。先列出布局改动，再实现。
不要为了美化加入新的页面、登录或动画依赖。
```

## 不知道为什么失败

```text
先不要重做应用。请检查当前错误属于哪一层：输入校验、连接器未关联、参数不匹配、权限、预览环境、设备返回或页面渲染。
给出能定位问题的最小检查步骤，并根据实际证据修改。没有实际返回时标为未知，不推测已经成功。
```

完成条件：修改前的问题能复现，修改后相同步骤能通过；原来正常的按钮没有被改坏。失败信息可以记录错误类别和课堂输入，不需要把整份私人日志贴给别人。

## 选择合适的修改方式

知识库将设计与能力分开：模板帮助搭起初始结构，组件补充页面，主题调整颜色、字体与样式；连接器和技能增加能力。只想换颜色时说“调整主题”，不要要求重建数据结构。修改失败时，原文提到可使用该轮回复的「回退」；先读当前界面提示并确认目标轮次，再检查功能是否恢复。开发对话回退不等于正式上架版本回滚。

```text
只修改当前应用的主题颜色与字体层级，保持页面结构、字段、现有数据和连接器调用不变。
列出本轮改动；若效果不合适，说明当前界面可用的回退方式。
```

资料依据：[官方知识库第 12–14 页](../../official/step-studio-knowledge/02-app-builder.md)。本节未重新执行回退操作。
