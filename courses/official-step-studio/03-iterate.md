# 03 · 一次只修一个可复现问题

[课程首页](README.md) · [下一课：测试](04-test.md)

先记录操作、预期与实际结果。修复前保留当前可用版本；主题调整与业务错误分开处理。

```text
问题：在作品列表选“工具”，打开详情后返回，分类变回“全部”。
预期：返回时保留分类和列表位置。
请只检查分类状态、路由与返回逻辑，保留现有组件、数据和外观。
先说明原因，再修改；复测“工具→详情→返回”和“全部→详情→返回”。
```

如果是外观问题，写清设备宽度、文字长度和截图位置；如果是调用问题，提供参数形状与错误信息，但移除凭据及私人字段。不要把原始截图中的敏感信息直接发进公开反馈。

使用主题时先小范围预览，再核对按钮对比度和文字换行。主题不会自动修复状态丢失、错误请求或权限问题。

完成条件：相同操作可重复得到预期结果，原有功能未退化；失败时能回到先前可用版本。
