# 04 · 从网页预览到手机验收

[课程首页](README.md) · [下一步：连接器](02-connectors.md)

按下面顺序测试；“尚未执行”是有效记录，不填写猜测的通过结果。

| 范围 | 怎么测 | 通过标准 |
| --- | --- | --- |
| 布局 | 窄屏、长标题、大字体 | 无遮挡、溢出和无法点击的按钮 |
| 导航 | 逐页进入、返回和切换 | 选中项、页面与保留状态一致 |
| 数据 | 空列表、零值、错误值 | 空态清楚，不将缺失数据伪装成零 |
| 操作 | 快速连点、取消和重试 | 无重复提交，执行状态真实 |
| 保存 | 重开页面或应用 | 数据保留或明确提示尚未持久化 |
| 连接器 | 成功、拒绝权限、网络失败 | 明确返回与错误，不用假结果代替 |
| 手机行为 | 在 Neo 观察实际效果 | 屏幕、声音、文件等结果与任务一致 |

```text
请生成本项目的测试清单，不执行公开发帖、发送消息或支付。
分别列出网页能测的项目、必须真机测试的项目和未实现功能。
每项用“步骤—预期—实际—结论”记录；没有真实执行记录就标待测。
```

示例记录：`分类筛选｜选择工具｜仅显示工具｜待执行｜待测`。

测试完关闭本轮启动的测试程序，撤销本轮临时授权；保留原先已有且仍需使用的权限。案例实测不能跨版本或跨组件套用。
