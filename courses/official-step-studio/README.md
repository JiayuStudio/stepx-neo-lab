# Step Studio 新手课程 · 新版

[研究所首页](../../README.md) · [新人分区](../../sections/start-here.md) · [教程归档区](../../sections/archive.md)

**2026-11-23 增量维护版。** 从最小界面开始，循序渐进接入官方应用构建器的 43 项连接器。本课程由 JIAYU STUDIO 编写，不是官方发布课程。

旧课程和旧截图已完整移入[早期版归档](../archive/official-step-studio-2026-10-20-early/README.md)。当前页面作为默认入口，旧记录不混入本版实测结论。

零基础先读[应用、智能体、技能与 HTML/CSS/JS/JSON/API](programming-basics.md)，完成不联网的小练习再进入平台课程。连接器采用 2026-11-23 快照；组件与其他路线保留各自截图和实操核查日期。

## 8 个组件，按需求选

[组件总表与选择建议](components.md)包括官方版本、截图、添加步骤、提示词和完成条件。先学底部导航栏、移动端卡片、胶囊标签；再学工具栏和图标；最后按需要选择图表或出行卡片。

## 进阶与其他路线

- [连接器分阶段练习](connector-index.md)：43 项目录，40 个练习；不要求一次学完。
- [数据、账号与后台](08-app-data.md)：从本地数据走向权限明确的共享目录。
- [智能体入门](09-agent.md)：整理会议纪要，不必先做界面课程。
- [技能入门](10-skill.md)：把固定输入输出变成可复用能力。
- [历史课堂案例](case-study.md)：旧版计算器的记录，独立于本版新练习。

高德、百度网盘和收款相关支付宝仍暂缓；主线不要求自行申请凭证。DeepSeek API 是[独立选修](../../guides/deepseek-api/README.md)，不用于替换官方网页的后端模型。
