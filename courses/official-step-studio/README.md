# 官方 Step Studio 新手课程

[研究所首页](../../README.md) · [新人分区](../../sections/start-here.md) · [官方 Step Studio](https://studio.stepx.com/)

从一句清楚的需求开始，在**官方 Step Studio 网页**做出自己的应用，再逐步接入手机能力。本课程由 JIAYU STUDIO 编写，官方网页截图用于操作教学，不是官方发布的课程。

**本轮不做需要自行申请 API 凭证的内容。** 当前官方目录 34 项中，31 项安排练习，高德地图、百度网盘及收款相关的支付宝暂缓。系统权限与 API 凭证不同：使用相机、位置等功能时仍可能出现手机权限提示。

每页都提供思路、步骤、可复制提示词与完成条件。先做第一课，再查需要的连接器；不必一口气读完全部能力名称。

## 连接器路线

1. **输入与查询**：计算器、云端天气、应用商店、搜索。
2. **即时反馈**：TTS、触觉反馈、手电筒、通用原子能力。
3. **系统状态**：设置、主屏、网络、蓝牙、蜂窝、音频、管家、反馈草稿。
4. **位置与天气**：定位、定位与GNSS、当前位置天气。
5. **日程与通信**：日历、时钟、短信草稿、拨号确认。
6. **文件与媒体**：文件、图库、相机、快记、录音、截图与录屏。
7. **背屏与组合**：先读状态，再做简单图案和组合功能。

## 本课程的实际验证范围
