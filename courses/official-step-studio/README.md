# 官方 Step Studio 新手课程

[研究所首页](../../README.md) · [新人分区](../../sections/start-here.md) · [官方 Step Studio](https://studio.stepx.com/)

从一句清楚的需求开始，在**官方 Step Studio 网页**创建应用、智能体或技能。课程已将官方群知识库的基础概念和流程融入正文，再配合原有连接器图文课练习。本课程由 JIAYU STUDIO 编写，官方网页截图用于操作教学，不是官方发布的课程。

**官方连接器主线暂不做需要自行申请 API 凭证的内容。** 当前官方目录 34 项中，31 项安排练习，高德地图、百度网盘及收款相关的支付宝暂缓。系统权限与 API 凭证不同：使用相机、位置等功能时仍可能出现手机权限提示。

## 第一次来，先选目标

先读 [00 准备与思路](00-start.md)，再选一条路线：

| 想做什么 | 学习顺序 | 最小作品 |
| --- | --- | --- |
| 带界面的应用与手机工具 | 01 → 02 → 03 → 04 → 按需选连接器 → 06 → 07 | 课堂计算器或天气播报卡 |
| 带用户端与后台的应用 | 先完成应用基础，再做 08，最后看 07 | 免费课程目录与编辑后台 |
| 按规则处理文字的助手 | 00 → 09 → 07 | 会议纪要助手 |
| 可重复调用的固定能力 | 00 → 10 → 07；想了解助手可先读 09 | 社媒文案技能 |

智能体和技能练习不要求先学完 31 个连接器。每条路线都先做一个小作品，记录网页预览与手机体验的实际结果。

每课包含目标、步骤、可复制提示词、完成条件和来源。三门新增练习尚未实际创建或在手机执行；请按课内测试表记录自己的结果。

## 连接器路线

1. **输入与查询**：计算器、云端天气、应用商店、搜索。
2. **即时反馈**：TTS、触觉反馈、手电筒、通用原子能力。
3. **系统状态**：设置、主屏、网络、蓝牙、蜂窝、音频、管家、反馈草稿。
4. **位置与天气**：定位、定位与GNSS、当前位置天气。
5. **日程与通信**：日历、时钟、短信草稿、拨号确认。
6. **文件与媒体**：文件、图库、相机、快记、录音、截图与录屏。
7. **背屏与组合**：先读状态，再做简单图案和组合功能。

## 本课程的实际验证范围

2026-10-20 已逐页核对当前账号可见的 34 个官方连接器，31 个教学页配有官方详情截图。课堂计算器在官方账号内创建；具体过程与结果见[案例记录](case-study.md)。其他练习是依据官方说明设计的教学任务，未逐项在 Neo 实机执行。网页可预览不代表硬件调用已经通过。

## 官方知识库如何融入课程

构建器选择与版本概念进入第 00 课；总控与助手进入第 01 课；主题和回退进入第 03 课；测试环境进入第 04 课；三类发布流程进入第 07 课；应用、智能体和技能示例改编为第 08–10 课。

[原文四章](../../official/step-studio-knowledge/README.md)仍作为查阅依据；[来源对应表](sources.md)说明各课来自哪些页。群文件来源由提供者确认，原群发布时间未提供。课程改编与官方原文、已有课堂实测分别标注。
