# 01 · 创建第一款应用：个人作品目录

[课程首页](README.md) · [下一课：组件库](components.md)

本课最小产物：一个能在手机宽度下浏览、筛选和查看详情的作品目录。无账号、无上传、无付费 API。此练习尚未实际创建。

## 操作步骤

1. 打开[官方首页](https://studio.stepx.com/)，选择「应用构建器」，产物选 APP。
2. 将下方需求放入消息输入区，开始构建。模型以账号当前可用选项为准；本次可见 Auto、Step 5 Preview、DeepSeek V4.1 Flash，不要求使用特定模型。
3. 等待项目生成，确认预览中出现列表、分类入口与详情；把课堂项目取名为「课堂作品目录」。
4. 到[组件库](https://studio.stepx.com/design/components)添加本课所需组件，按[下一课](components.md)逐个完成。不要把“添加”当作已经完成接线和测试。
5. 先保留有效结果，再逐步增加收藏和本地保存。

## 第一条提示词

```text
创建一个手机优先的个人作品目录 App。先用 3 条明确标注的虚构示例，分类为网页、App、工具。
首页显示名称、分类、简介和查看详情按钮；详情显示完整说明与返回入口。
先实现分类筛选和详情切换，不接登录、支付、上传和外部 API，不放真实下载链接。
组件计划为底部导航栏、移动端卡片、胶囊标签；添加后读取组件实际用法再集成。
请先说明页面与数据结构，再完成最小可操作版本；保留空列表和长标题的处理。
```

## 怎么继续提需求

先看当前页面，再提出一项改动，例如“分类切换后保留列表位置”。发现报错时复制错误内容，写清点击顺序；不要反复发送“全部重做”。

官方知识库中的总控与助手协作可用于拆分任务，但每次仍要说明改动范围和验收条件，不把代理自述当测试证据。

## 完成条件

三个示例均能进入详情，返回列表后分类正确；窄屏没有横向溢出；界面清楚标为示例，不提供无效下载按钮。
