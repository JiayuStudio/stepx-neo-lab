[课程首页](README.md) · [下一课：创建应用](01-create.md)

本课程使用 [studio.stepx.com](https://studio.stepx.com/) 的**官方 Step Studio**。研究所另有自研「StepX Neo Studio」，名称相似，操作界面和构建流程不同；请勿混用两份教程。

## 准备

登录官方网页，先根据目标选择构建器。下方应用主线选择「应用构建器」中的 APP；网页游戏是另一种产物。准备一个全新的课堂项目，使用虚构文本、公开城市或专用测试文件。

第一课不需要自行申请 API Key，也不要求先学编程。要验证手机连接器，需要具备对应能力的 Neo 与实际权限；电脑浏览器先用来检查页面布局和错误提示。

## 先选一条路线

官方知识库把作品分为三类构建方式，先选目标，再学对应操作。

| 你的目标 | 选择 | 本课程练习 |
| --- | --- | --- |
| 做带按钮和页面的工具、配套后台或网页游戏 | 应用构建器 | [课堂计算器](01-create.md) → [课程目录与后台](08-app-data.md) |
| 做按固定规则回答问题的助手 | 智能体构建器 | [会议纪要助手](09-agent.md) |
| 把一种处理规则反复用于不同作品 | 技能构建器 | [社媒文案技能](10-skill.md) |

没有明确方向，可以先做不挂连接器的会议纪要助手；想学习手机能力，则按应用主线从计算器开始。三条路线不要求全部完成。

## 登录与作品管理

原知识库说明：用手机号和短信验证码登录，首次登录创建账号。在「我的作品」搜索、置顶或重命名课堂项目，避免与正式作品混淆。先取一个容易识别的练习名；不要通过删除旧作品来重新开始。模型选择随平台更新，先使用页面当前可用选项。

## 分清作品的三个版本

| 版本 | 用途 |
| --- | --- |
| 开发版本 | 当前编辑与预览的内容 |
| 测试版本 | 用于设备体验与验证 |
| 正式版本 | 发布后交付使用；后续修改需要重新测试并发布 |

开发环境与正式环境的数据相互独立。预览时录入的测试内容，不应被当作上线后自动存在的业务数据。数据练习见[第 08 课](08-app-data.md)。

## 三个容易混淆的概念

| 概念 | 这次怎么处理 |
| --- | --- |
| 官方账号登录 | 用来进入 Studio 和保存课堂项目 |
| 手机系统权限 | 实机功能需要时，按系统提示决定是否开启 |
| 自行申请开发者凭证 | 本轮暂不做；不要为了跟上课程注册地图或网盘开发者应用 |

## 把想法写成三行

- **谁在什么时候用**：我想随手计算一个算式。
- **输入与动作**：输入 `12*(3+4)`，点击「计算」。
- **看到什么才算完成**：结果显示 `84`；出错时解释原因，不能一直转圈。

先别把天气、日历、聊天和收款全部放进第一款应用。一项功能能完成输入、执行和反馈后，再加第二项。

## 思路提示词

```text
我想做一个供新手使用的口袋计算器。请先把需求拆成：目标用户、一个主要场景、输入、按钮动作、结果、失败情况和验收条件。
本轮只做一个页面、一个核心功能，不增加登录、数据库、付费或额外连接器。
说明哪些部分可以网页预览，哪些必须手机验证。先给简短方案，再按方案实现。
```

完成条件：你能不用技术名词说清“输入什么、按什么、看到什么”。
