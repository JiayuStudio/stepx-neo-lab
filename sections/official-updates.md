# 官方群信息

[研究所首页](../README.md) · [新人入门](start-here.md) · [原创教程与研究](guides.md)

**官方发布，研究所整理。** 本区用于归档 STEPX / Step Studio 官方在社区群发布、且可以公开转述的信息，并保留原发布时间、出处和适用范围。维护者自己的实测与判断放在[教程与研究](guides.md)，不作为官方结论。

## 公告时间线

目前尚未归档公告。这表示本栏目暂未收录内容，不表示官方没有发布消息。

后续按以下主题归档：

- **系统与固件更新**：发布时间、适用版本、变更与官方说明。
- **Studio 与开发能力**：新功能、接口、开发教程与官方示例。
- **账号与服务说明**：官方公布的适用条件、生效时间与查询入口。
- **社区活动与反馈**：官方活动安排、反馈渠道和截止时间。

## 信息条目格式

| 字段 | 记录内容 |
| --- | --- |
| 标题 | 这条公告说明什么 |
| 原发布时间 | 官方发布的日期，必要时注明时区 |
| 官方出处 | 官方公开链接；群公告注明来源类型及官方身份核实情况 |
| 核心内容 | 简洁转述原消息，保留条件、限制与有效期 |
| 适用范围 | 对应产品、版本或用户范围 |
| 后续更新 | 官方补充、更正或失效日期 |

## 官方公开入口

- [Step Studio](https://studio.stepx.com/)：官方应用、智能体与技能创作平台。

有需要归档的官方公告，可在本仓库 [Issue](https://github.com/JiayuStudio/stepx-neo-lab/issues) 中提供官方公开链接或可公开转述的内容及日期。未经核实的群聊转述暂不进入公告时间线。
