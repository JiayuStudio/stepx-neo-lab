## 分类说明

后续按以下用途整理：

- **效率与日常工具**：适合在 Neo 上使用的实用应用。
- **背屏与个性化**：点阵显示、动画与相关工具。
- **开发辅助**：有可安装 APK 的编辑、调试和开发工具。
- **社区游戏**：其他作者开发、适合 Neo 的游戏。

每项会写明推荐理由、测试版本与适用范围；「仓库可访问」「有 APK 下载」和「Neo 实机通过」分别记录。

## 每个条目包含什么

| 字段 | 内容 |
| --- | --- |
| 应用 / 作者 | 项目名称、获准公开的作者或组织署名；暂不显示时说明原因 |
| 用途与推荐理由 | 解决什么问题，为什么值得尝试 |
| 原仓库 | 原作者维护的源码仓库；未提供时明确标注 |
| APK 入口 | 原项目 Releases、作者指定渠道或社区群来源说明 |
| 版本与日期 | 本次查看或实测的版本、检查日期 |
| Neo 验证 | 已实测 / 未实测，以及具体通过或未通过的功能 |
| 许可与限制 | 仓库许可、收费情况、已知兼容性限制 |

有值得推荐的项目，可以在本仓库提出 [Issue](https://github.com/JiayuStudio/stepx-neo-lab/issues)，附上原仓库链接和推荐理由。没有 Release APK 的源码项目可先作为开发参考，不列为可直接安装的应用。
